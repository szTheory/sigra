Logo system

D4 Linked Rail: the ratified Sigra mark system.

The D4 Linked Rail is a fully integrated typemark. The ember-colored rail block above the i and the extended g tail form a single bracketing rail — the mark is structural in the letterforms, not applied on top.

Lockup set

Integrated typemark anatomy

  • Rail block (ember): the solid ember-colored rectangle positioned above the i tittle replaces the conventional dot. It is the ember accent, not decorative punctuation.
  • Extended g tail: the descender of the lowercase g is drawn out to align horizontally beneath the rail block, completing the bracketing rail on the baseline side.
  • Together, the rail block and the extended tail create one continuous vertical rail that brackets the interior letterforms — giving the mark its name and differentiating it from any clip-art assembly.

Clearspace and minimum sizes

  • Clearspace: reserve space equal to the mark height on all four sides of the lockup. Do not crowd the mark with text, borders, or other graphic elements.
  • Primary lockup: 120 px minimum width in digital contexts.
  • Free-standing mark: 24 px minimum rendered size.
  • Favicon: 16 px minimum; use the favicon.svg source — it is optimised for square display at very small sizes.
  • Monochrome mark: 24 px minimum; do not use monochrome below this size or the rail bracket becomes illegible.

Use

  • Primary lockups for brandbook, landing, README visual, and talks.
  • Subtitle lockup for tall-format contexts: slide headers, social preview cards, and two-line display surfaces.
  • Free-standing mark for UI accents, favicon, package avatar, social avatar, and compact cards.
  • Monochrome mark for print, one-color embossing, and restricted-color contexts.
  • Social card SVGs as the authoritative source for all OpenGraph and platform preview images.

Misuse — do not

  • Do not add a rectangular container, badge, or background shape behind the mark — the D4 rail block is not a badge element.
  • Do not rotate, skew, or mirror any part of the lockup.
  • Do not recolor the ember rail block using ember-300, ember-200, or any non-700 ember step — the rail block must use ember-700 #c2410c on light surfaces.
  • Do not use the monochrome mark at sizes below 24 px — at that scale the rail bracket degrades to visual noise.
  • Do not apply drop shadows, gradients, or bevels to any element of the lockup.
  • Do not use the black wordmark SVG on dark surfaces — use logo-primary-dark.svg instead.

Seven libraries, one coherent system.

The szTheory OSS suite uses a shared design vocabulary while each library owns its mark, accent hue, and domain metaphor. This keeps the suite coherent without forcing visual uniformity.

Rule 1 — Shared wordmark typeface

Inherit Space Grotesk v2.0 (OFL, wght 700) as the suite wordmark typeface. All seven library logotypes use this face at the same weight for a recognisable family relationship.

Rule 2 — Domain-specific mark

Each library adopts a unique mark that reflects its domain metaphor. The mark must be legible at 16 px (favicon), 24 px (compact UI), and in monochrome. Do not reuse or adapt Sigra's D4 rail system for a sibling mark.

Rule 3 — Hue separation

Each library selects an accent hue at least 15° from every existing sibling's hue on the color wheel. Sigra occupies ember ~15°. New libraries must verify the separation against all currently ratified sibling hues before committing a color.
