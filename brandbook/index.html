Executive judgment

Strong strategy. Missing public system. Fixed without a redesign.

Keep

The README and launch docs are credible because they name ownership, caveats, and proof. That is Sigra's strongest brand asset.

Tighten

Turn implicit voice, visual, token, and artifact choices into citable repo files so future work does not drift.

Do not do

No mascot, no generic auth lock illustration, no blue-purple gradients, no "seamless next-generation" language.

Anti-traits

Logo system

Core Rails lockup plus small mark. Direction ratified.

Phase 167 selected Option A: Core Rails. Use the current logo files as the final source set; keep logo options as review history, not the active logo source.

Use

  • Primary lockup for brandbook, landing, README visual, and talks.
  • Mark for favicon, package avatar, social avatar, compact cards.
  • Monochrome mark for print, restricted color, and low contrast contexts.

Avoid

  • No gradients, bevels, shadows, rotations, or mascot additions.
  • No tiny wordmark where the icon mark is more legible.
  • No unrelated lock or shield icons beside the mark.

Voice
