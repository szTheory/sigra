Round 3 exploration / integrated typemarks / rail motif

Typemarks, not icon + text.

Round 3 moves past the mark-beside-text pattern that rounds 1–2 (and the rest of the Elixir ecosystem) lean on. Four candidates work the rail motif directly into the letterforms, two refine the combination lockup with boundary-breaking composition, and one wildcard stacks the word. Every candidate passed the 16/32/54px and hero render gate in light and dark before landing here.

  • No background container
  • Tight mark–type proximity
  • Subtitle-free primary
  • ≥2 integrated typemarks
  • Not mark-beside-text
  • Ember hue 15–40° only
  • Human gate at Phase 180

How to read this board

Judge each candidate at the favicon row first — 16px is the kill test. Then check the light/dark lockups for integration coherence: the rail motif should read as part of the letterform, not decoration beside it.

Subtitle previews pair each lockup with HTML text; no subtitle is baked into any SVG.
