# Sigra Rail Accent Variations

This folder preserves source studies for the Rail Accent logo family. Active production assets live in the parent `brandbook/` directory.

## System Criteria

- Primary lockups use the Sigra wordmark without subtitle or slogan.
- The mark sits close to the wordmark and stays secondary to the name.
- Favicon uses the same Rail Accent mark geometry as the primary mark.
- Rail/accent geometry remains the core visual language.
- Light and dark usage stays legible through explicit surface-specific assets.
