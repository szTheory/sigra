Rail Accent specimens

Primary lockup / no slogan / tight mark gap

Make the rail do less.

The Rail Accent carries Sigra best when it stays restrained: visible rails, a confident wordmark, and small marks that stay legible without turning into generic app badges.

  • No subtitle
  • Bigger wordmark
  • Tight mark gap
  • Tile only when useful
  • Light and dark first

System behavior

The primary lockup is transparent and wordmark-led. The favicon uses the same Rail Accent geometry as the free-standing mark.

Light and dark lockups use explicit assets so contrast stays predictable when the logo is embedded as an image.
