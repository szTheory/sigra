## Fonts

- `fonts/web/fonts.css`
- `fonts/variable/InstrumentSans[wdth,wght].ttf`
- `fonts/variable/RedHatMono[wght].ttf`
- `fonts/OFL-InstrumentSans.txt`
- `fonts/OFL-RedHatMono.txt`

All logo SVGs are flat filled paths (no live text, no strokes, no masks) in exact brand colors, transparent. `light` files are for light backgrounds, `dark` for dark ones; `mono-ink` and `mono-bone` are one-color drawings, not recolors. `lockup` is the typemark and `symbol` is the dotted i alone; the favicon files are the dotted i drawn for exactly 16 and 32 px. The avatar is the one file with a plate. `icon/favicon.svg` swaps its stem and square with the device theme; the ICO is light ink only. `docs/sigra-exdoc.css` colors code in ExDoc and has not been run in a real ExDoc build. Fonts are SIL Open Font License 1.1 (licenses in `fonts/`). This edition has no logo animation and no sound files.
