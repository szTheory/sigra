# v1.10 — Assumed first production feature bundle (adopter scope)

**Purpose:** Anchor milestone **ACF-** requirements and docs to a concrete “intermediate solo production” stack. **Edit this file** if your real app differs before prioritizing phase work.

## In scope for “dogfood confidence” (default assumption)

| Area | Assumption |
|------|------------|
| **Sessions** | Database-backed browser sessions with secure cookies (HTTPS, correct `SameSite`, reverse-proxy aware). |
| **UI** | Phoenix **LiveView** for generated Sigra pages where installed. |
| **Password / email** | Email/password + confirmation; password reset available. |
| **OAuth** | At least **one** social/OIDC login path (e.g. Google-class) using shipped Assent strategies. |
| **MFA** | **TOTP** + backup codes; trust-this-browser optional. |
| **API** | **Optional** — PAT/JWT not required for baseline; if you use them, add explicit checklist rows in a follow-up edit to this file. |
| **Organizations** | **Generator default** — treat org switcher + membership as in play unless the host installed `--no-organizations`. |
| **Admin** | **Generator default** — treat default-on admin as in play unless `--no-admin`. |
| **Passkeys** | **Optional** — include only if not installed with `--no-passkeys`. |
| **Mail** | Production uses either **Oban-backed** Swoosh delivery or a consciously chosen inline path. |
| **Host environment** | Public HTTPS behind a **reverse proxy** (e.g. Fly.io, Render, or nginx/caddy) — not bare `http://localhost`. |

## Out of scope for this bundle (still valid Sigra features)

- **Lockspire** / optional **`sigra_lockspire`** glue — see `.planning/decisions/001-defer-sigra-lockspire-glue-package.md`.
- **Full SEED-002** library-wide `log_safe/3` conversion — bounded batches only when tied to a flow you ship.
- **SEED-001** loud-launch human matrix — reserve for a public-announcement milestone.

## Maintainer action

Before executing phases, confirm or amend the table above so **ACF-** verification targets the same surface your first production app uses.
