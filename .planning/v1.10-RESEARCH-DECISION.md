# v1.10 — Research gate

**Decision:** Skip parallel ecosystem research for this milestone.

**Reason:** Scope is **adopter confidence / dogfood integration** (docs, checklists, upgrade stub, explicit non-goals) — not new auth primitives or new third-party integration classes. Friction should be driven by **repro notes** from real hosts, not stack discovery.

**When to run research instead:** If a future milestone adds a **new** integration class (e.g. first-class deployment target, new optional backend, or net-new protocol), use `/gsd-new-milestone` research path for that milestone.
