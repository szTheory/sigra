# Deferred Todo Ledger

Items in this directory are deliberately not represented as complete. They were moved out of `todos/pending/` during the v1.48 closeout reconciliation because they are future product work, accepted non-blocking debt, manual operator/repository administration, or work explicitly outside the v1.48 B2C alpha scope.

The original files are preserved intact, including historical `status: pending` metadata where present. Their directory placement and `.planning/OPEN-ARTIFACT-RECONCILIATION-v1.48.md` are the current disposition. Promote an item back to `todos/pending/` only when a milestone explicitly accepts it into scope.
