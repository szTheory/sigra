# Milestone v1.27: ENT-SSO

**Status:** ✅ SHIPPED 2026-05-26
**Phases:** 122–126
**Total Plans:** 17

## Overview

v1.27 closes the largest remaining B2B-adoption wedge in Sigra's current scope: organization-scoped enterprise sign-in. The milestone stayed OIDC-first and bounded. It did not try to become a hosted identity platform, a directory-sync product, or an opinionated authorization system. Instead, it turned the existing organizations, OAuth, audit, and generated-host substrate into one truthful enterprise contract across setup, routing, reconciliation, enforcement, and operator proof.

The milestone ran in five deliberate steps:

- **Phase 122 — connection contract and activation truth** — add the organization-bound enterprise connection model, OIDC validation lifecycle, and truthful operator-facing setup state.
- **Phase 123 — org-aware routing** — add canonical org-scoped enterprise entry, bounded email-domain discovery, and signed callback context revalidation.
- **Phase 124 — JIT reconciliation** — land safe enterprise identity reconciliation, invitation reuse, JIT membership creation, and first-session org/audit truth.
- **Phase 125 — SSO-only enforcement** — let organizations require enterprise login while preserving explicit break-glass recovery for allowed members.
- **Phase 126 — proof, diagnostics, and docs** — close the milestone with generated-host proof, installer parity, bounded troubleshooting posture, and canonical enterprise docs.

## Milestone Summary

**Decimal Phases:** None.

**Key accomplishments:**

1. Sigra now has an organization-bound enterprise connection model with truthful OIDC validation and activation refusal semantics.
2. Enterprise sign-in now routes through canonical organization entry or bounded exact-match domain discovery instead of loose provider selection.
3. Enterprise callback handling now reuses current org, membership, invitation, and identity substrate for safe JIT reconciliation and first-session truth.
4. Organizations can require enterprise login while preserving explicit break-glass users as the only password-only recovery path.
5. Generated-host, example-app, installer output, canonical docs, and milestone proof now describe the same bounded enterprise contract.
6. The milestone closed with retroactive verification authority for Phases 123–125 and a passing v1.27 milestone audit.

### Key Decisions

- Stayed OIDC-first and organization-scoped instead of widening the milestone into generic enterprise identity breadth.
- Kept enterprise routing, reconciliation, and enforcement library-owned so generated hosts remain thin truth mirrors.
- Required explicit break-glass recovery rather than hidden local-auth fallback under SSO-only policy.
- Used repaired-form retroactive verification artifacts for Phases 123–125 so the milestone closes on authoritative proof instead of summary-only claims.
