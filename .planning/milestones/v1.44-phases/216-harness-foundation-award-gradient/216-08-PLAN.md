<objective>
Close BLOCKER Gap 1 (probe-scope vs DOM-scope mismatch). Thread a board-element root
through the probe engine so all nine probes scan only within the board subtree —
matching the board-scoped `dom.html` outerHTML capture — instead of scanning the
whole `/admin/_design` gallery page. This restores the D-09 "cite-and-flip
impossible by construction" guarantee: every finding's anchor now resolves inside
the already-board-scoped captured DOM.

Root cause (established by verification): 8 of 9 probes hard-code
`document.querySelectorAll('[class*="sg-"]')` and scan the entire page, attributing
gallery chrome (`.sg-nav-link`, `.sg-breadcrumb__item`, `.sg-scope-pill`) and every
OTHER board's elements into the currently-captured single board's bundle. Result:
526/869 (60.5%) of MG-5 findings have anchors absent from its board-scoped `dom.html`,
so `evidence-anchor-check.mjs` exits 1 on every real bundle.

Directed fix (locked, do not re-derive): scope the probes to the board element.
Full-page capture is DISQUALIFIED — all boards share one page, so a full-page
`render_sha256` would flip every board's SHA whenever any board changes.

Also folds in refinement W1 (verified against real bundles): `evidence-anchor-check.mjs`
destructures `{ finding_id, anchor, class: probeClass }` from each finding, but the real
`findings.json` emitter (probes.ts) emits `probe_class` and carries NO `finding_id`/`class`
keys. Consequences on real bundles: `probeClass` is always `undefined` (the
`GEOMETRY_ONLY_CLASSES` geometry-note path is dead code that never fires) and every FAIL
message prints `undefined` for the finding id. The anchor-presence check itself is unaffected
(it needs only `anchor`), so W1 does NOT invalidate the scope fix — but the first trusted
end-to-end run (216-09) would surface `undefined` ids in this exact HARNESS-02 guard. Task 3
reconciles the emitter TOWARD the D-22 contract (`finding_id = sha256(surface \0 class \0
anchor)`, the Phase-217 AUTOFIX-01 seam) so findings.json carries `finding_id`/`surface`/
`class`/`anchor`, the guard reads real values, and the settled-findings.tsv key + Phase 217
fix queue + this guard all agree on one shape.

Purpose: Make evidence-anchor-check able to exit 0 on real bundles with REAL finding ids
(proven live in 216-09).
Output: A board-scoped probe engine + in-scope seeded-defect tests that still pass + a
D-22-shaped findings emitter and a W1-corrected anchor-integrity guard.
</objective>
