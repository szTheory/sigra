<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| impersonating request -> sensitive mutation endpoints | High-value account-security actions must fail closed while impersonation is active |
| LiveView event handlers -> Accounts context | Event handlers can bypass controller plugs unless the Accounts layer also enforces the rule |
| direct-path Accounts calls -> audit trail | Denied security mutations must still leave evidence |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-29-12 | E | sensitive account mutations during impersonation | mitigate | Per D-12 and D-13, route controller and LiveView state changes through a shared impersonation gate plus direct Accounts guards. |
| T-29-13 | R | denied sensitive-operation attempts | mitigate | Per D-14, emit explicit denial copy and audit events instead of silently hiding or no-oping blocked actions. |
| T-29-14 | T | LiveView-only mutation paths | mitigate | Guard mutation handlers in `Example.Accounts` as well as request plugs so direct-path calls fail closed. |
</threat_model>
