Phase 33 / Plan 02 — INT-05 Presenter Re-wire (library-owned Detail loader + LiveView render).

The Phase 28 recent-audit preview on the user-detail page bypasses Phase 30's `Sigra.Admin.Audit.Presenter.present/2`, so impersonation audit rows render their raw `admin.impersonation.start` action string instead of the "Impersonation" badge + actor-summary label that the Phase 30 per-user explorer already renders from the Presenter output. This breaks the invariant "audit rows are always Presenter-shaped before leaving the Sigra admin layer" (D-01) and makes the preview → full-log information scent diverge from the explorer.

This plan flips `Sigra.Admin.Users.Detail.recent_audit_preview/3` in place so that:
- It owns query AND the Presenter call (mirrors `Sigra.Admin.Audit.Explorer.list/4` load+present ownership, D-01).
- It returns `[map()]` of Presenter-shaped rows with guaranteed keys `:id`, `:inserted_at`, `:action_label`, `:action_badge`, `:actor_summary` (plus the other Presenter keys).
- `users_by_id` lookup lives inside `Detail` and mirrors `Sigra.Admin.Audit.Explorer.load_users/2` exactly (D-04).
- The `@spec` and `@doc` explicitly state Presenter-shaped output (D-03).

The LiveView `user_show_live.ex` is updated to consume Presenter row keys (`row.action_badge`, `row.action_label`, `row.actor_summary`) in a strict subset rendering (D-05/D-06) — the preview shows fewer fields than the explorer, never more and never different (information-scent invariant, D-07).

defp load_users(config, events) do
  ids =
    events
    |> Enum.flat_map(fn event -> [event.actor_id, event.effective_user_id, event.target_id] end)
    |> Enum.filter(&is_binary/1)

      case audit_schema(config) do
        nil ->
          []

            [subject_user_id: user_id]
            |> maybe_put_audit_scope(admin_scope)

            audit_schema
            |> Sigra.Admin.Audit.Query.build(filters)
            |> order_by([event], desc: event.inserted_at, desc: event.id)
            |> limit(^@audit_preview_limit)
            |> config.repo.all()

          users_by_id = load_audit_users(config, events)
          Sigra.Admin.Audit.Presenter.present(events, users_by_id)
      end
    end
