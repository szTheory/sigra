<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Runtime probe to target repository configuration | Capability probing is confined to disposable repositories and completes before the target repo's hook path or coordinator files are changed. |
| Coordinator hook to linked worktree HEAD | A direct symbolic HEAD update must be rejected while another process owns the common-directory coordinator lock. |
| Runtime probe to local deletion | Only the exact Git executable whose probe passed can use the local deletion path; all registered worktrees must still resolve the verified shared hook. |
| Test fixture to project repository | Positive deletion occurs only in a disposable fixture; active-project refs, worktrees, config, origin, and PRs remain untouched. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-245-13-01 | Tampering | Unsupported Git executable | high | mitigate | Probe direct symbolic HEAD enforcement using the exact executable and reject unsupported behavior before target configuration changes. |
| T-245-13-02 | Race condition | Linked-worktree attachment during local delete | high | mitigate | Verify all worktree hook paths, hold the common-directory coordinator lock through final checks and compare-and-delete, and prove a competing attach is rejected. |
| T-245-13-03 | Tampering | Test fixture ref/config writes | high | mitigate | Run both accepted and rejected mutation cases only in disposable repositories and compare the active project's refs/config/worktree state before and after. |
| T-245-13-04 | Denial of service | Stale lock or transaction lease | medium | accept | Preserve existing fail-closed behavior and require explicit operator reconciliation; never reclaim stale state automatically. |
</threat_model>
