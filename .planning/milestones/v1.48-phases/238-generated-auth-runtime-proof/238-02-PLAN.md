<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| browser forms → generated auth routes | User-controlled credentials and tokens cross LiveView/controller validation boundaries. |
| generated mailer → development mailbox → browser | Authentication links are bearer material and must be selected for the intended recipient and purpose. |

## STRIDE Threat Register — OWASP ASVS L1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-238-05 | Spoofing | mailbox recipient/link selection | high | mitigate | Match exact recipient and route purpose, select newest mail, and navigate only a URL normalized to the generated host. |
| T-238-06 | Information Disclosure | browser/test diagnostics | high | mitigate | Never print passwords or token URLs; keep credentials deterministic but test-only and ephemeral inside the disposable host. |
| T-238-07 | Repudiation | reset completion | medium | mitigate | Prove old-password rejection and new-password success after reset rather than crediting submit/redirect alone. |
| T-238-08 | Denial of Service | mailbox readiness | medium | mitigate | Use bounded observable polling with descriptive failure; no unbounded loop or elapsed-time sleep. |
</threat_model>
