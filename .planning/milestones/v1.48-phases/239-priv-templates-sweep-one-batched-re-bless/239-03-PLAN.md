## SAFETY RULESET (CRITICAL — do not bypass)

1. **Scope is the counterpart set, never `test/example/` as a whole** (D-19, SC-4). The repo-wide
   token surface there is 476 lines / 94 files; the mandated scope is 110 lines / 30 files. A
   `grep -rl` over `test/example` would blow the scope silently.
2. **Every edit names an explicit path** (D-23). No globbed or piped rewrite.
3. **This commit's diff is entirely under `test/example/`.** Asserted in Task 3.
4. **Where the counterpart carries no token, record `n/a — already absent`** — never manufacture a
   phantom edit to make the checklist look symmetrical.
5. **`mix ci`, never root `mix test`** (Standing Constraint 3). Root `mix test` misses both
   formatting and the `test/example` lane.
6. **A zero-match grep must be a measurement, not a fatal status.** Under `set -eo pipefail` a
   command substitution whose pipeline starts with a grep that finds nothing aborts the script on
   the **success** path — verified:
   `bash -c 'set -eo pipefail; n=$(printf "" | grep -E zzz | wc -l); echo reached'` prints nothing
   and exits 1. This plan's counterpart assertion is "the grep returns zero", exactly that shape.
   Use a brace group with `|| true` inside the substitution:
   `n=$( { grep -nE "$U" $(cat "$L") || true; } | wc -l | tr -d " ")`. Never a bare
   `grep | wc -l` substitution.
7. **Name a missing prerequisite rather than letting it surface as an opaque failure.** `mix ci`
   needs Postgres (CLAUDE.md, "Local development prerequisites"). Probe the socket first so an
   unmet prerequisite says so, instead of arriving as an inscrutable `ci.install_golden` failure.
