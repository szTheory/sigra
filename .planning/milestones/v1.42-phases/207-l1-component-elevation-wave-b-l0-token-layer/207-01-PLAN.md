  Structure mirrors admin-css-conformance.sh:
  - ROOT auto-derived: ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
  - Default CSS target: CSS_FILE="${CSS_FILE:-${ROOT}/priv/templates/sigra.install/admin/sigra_admin.css}"
  - Default doc target: DOC_FILE="${DOC_FILE:-${ROOT}/guides/reference/admin-token-reference.md}"
  - Accept overrides: positional arg or --css <path> for the CSS file; --doc <path> for the doc; reject unknown --args with exit 2; provide a usage()/--help block

    grep -oE '^[[:space:]]*--sg-[a-z0-9-]+[[:space:]]*:' | grep -oE -- '--sg-[a-z0-9-]+' | sort -u
  This yields the sorted unique set of token NAMES defined in :root.

  SET B (tokens documented in the doc): extract backtick token literals:
    grep -oE '`--sg-[a-z0-9-]+`' "$DOC_FILE" | tr -d '`' | sort -u

  DIFF: use comm on the two sorted sets:
    comm -23 SET_A SET_B  -> tokens defined in :root but NOT documented (fail: undocumented token)
    comm -13 SET_A SET_B  -> tokens documented but NOT in :root (fail: stale doc row)
  If either list is non-empty, print the offending tokens with a labelled FAIL line and set violations=1.

  On success: echo "admin-token-completeness: PASS — N tokens, :root == doc" (N = the matched count, 100 at baseline) and exit 0; else exit 1.

  chmod +x the file. Do NOT inline a fenced code block of the literal forbidden patterns — describe the grep/comm by behavior only.
