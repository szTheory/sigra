  Structure mirrors quality-ledger-monotonic.sh:
  - ROOT auto-derived: ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/../.." && pwd)"
  - Default CSS target: CSS_FILE="${CSS_FILE:-${ROOT}/priv/templates/sigra.install/admin/sigra_admin.css}"
  - Accept a positional argument override: if $1 is provided and does not start with --, treat it as the CSS_FILE path; otherwise accept --css <path> flag; reject unknown args with exit 2
  - fail() helper echoes "admin-css-conformance: FAIL: $*" to stderr and exits 1
  - Two checks in sequence, each with its own violation counter:

  CHECK 1 — no transition: all (per D-05 criterion a, D-06): grep for the literal string "transition: all" (case-sensitive, whole-property). If grep returns any matches, emit a fail line naming each matching line number, set violations=1.

  CHECK 2 — no raw hex outside :root blocks (per D-05 criterion b): This is more nuanced. The approach: extract lines that are NOT inside a :root { ... } block, then grep those lines for hex color literals (#[0-9a-fA-F]{3,6}). Strategy: use awk to track when we are inside a :root { block (increment depth on opening brace after :root, decrement on closing brace; emit lines not inside :root). Pipe that to grep -E '#[0-9a-fA-F]{3,6}'. If any matches, emit fail lines, set violations=1.

  Note: the dark-mode `:root` inside `@media (prefers-color-scheme: dark) { :root { ... } }` is also a token-definition block; the awk tracker must handle nested braces correctly — track brace depth, enter :root protection on the line containing ":root {", exit when depth returns to the pre-:root level.

  After both checks: if violations == 0, echo "admin-css-conformance: PASS — ${CSS_FILE}" and exit 0; else exit 1.

  chmod +x the file.
  </action>
