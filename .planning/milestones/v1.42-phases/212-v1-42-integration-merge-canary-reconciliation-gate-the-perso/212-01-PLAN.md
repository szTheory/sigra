<objective>
Close GATE-01 (canary reconciliation) so the FULL v1.42 backlog can merge cleanly to
origin/main on PR #63 with BOTH snapshot-drift lanes green. There are three
mechanically-distinct drift classes; each has its own reconciliation path:

1. The **impersonation-banner mobile canary** — its Phase 204-03 WCAG contrast fix
   (commit `c96749fa`, `.vt-status-pill` corrected to >=4.5:1) left it `modified` vs
   origin/main. A canary is NEVER allowlistable, and re-designating it as `added`
   in-PR is a PROVEN NO-OP: `snapshot-canary-guard.sh` diffs the working tree against
   the base with `git diff --name-status origin/main` (guard line 79), which ignores
   the index — so `git rm --cached` + `git add` leaves the canary `modified` and the
   guard hard-fails (guard line 104). Per D-13, the canary is reconciled by a
   **prerequisite recapture PR merged to origin/main FIRST** via the sanctioned
   `admin_checkpoint_recapture` CI job (ci.yml:1687-1855): it recaptures the checkpoint
   baselines in ubuntu CI with `--update-snapshots`, opens `ci/recapture-admin-checkpoints-<run_id>`,
   and the gate is HUMAN VISUAL REVIEW of the PNG diffs. Once that PR merges to
   origin/main, origin/main carries the WCAG-fixed mobile bytes and PR #63's canary
   diff reads byte-green.

2. Four **legitimate v1.41-backlog checkpoint drifts** (`audit-explorer`, `user-audit`,
   `global-user-index`, `org-scoped-admin`) — cumulative deltas from phases 200-204,
   not v1.42 regressions (D-02). Declare one slug line each in
   `test/example/priv/playwright/snapshot-allowlist` in the same PR #63 diff. Per D-15,
   verify `user-sessions`'s classification on a clean checkout and allowlist it too if
   it surfaces as drift.

3. The **design-lane v1.41-backlog drifts** (D-14): 4 added slugs (`board-cfg-audit`,
   `board-cfg-overview`, `board-cfg-user-detail`, `board-cfg-users-list`) and 11
   modified slugs (`board-mg-1`..`board-mg-11`) — none is the `board-notice` canary.
   Declare them in `test/example/priv/playwright/snapshot-allowlist-design` in the same
   PR #63 diff.

Exit condition (D-04): BOTH `scripts/ci/snapshot-canary-guard.sh --base origin/main`
invocations exit 0 on PR #63 — the fast_checks "Snapshot drift guard (canary allowlist)"
step (ci.yml:100-101) AND the "Snapshot drift guard — design lane" step (ci.yml:102-108).

Purpose: unblock PR #63's fast_checks + ci-gate on both drift lanes.
Output: two edited allowlists (in the PR diff) + a merged recapture PR on origin/main
re-baselining the canary with the WCAG fix preserved.
