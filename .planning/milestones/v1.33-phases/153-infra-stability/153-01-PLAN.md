## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ExUnit test process -> `Sigra.Test.PostgresRepo` | Untrusted test processes cross into the shared sandbox owner/pool boundary. |

| Library test harness -> example/browser lanes | The library-side fix must not leak test-only sandbox semantics into seeded dev-server browser proof. |
