**Key decisions**

- **Hex-facing honesty:** `mix.exs` description and links call out core vs optional stacks; `:maintainers` omitted per Hex deprecation.  
- **Changelog semantics:** Hex `[0.x.y]` headings stay canonical; planning **v1.x** labels trace to `MILESTONES.md` / roadmap archives.  
- **Evidence URLs:** Tag-scoped GitHub blob URLs for `.planning` pointers in README / maintainer docs where ExDoc cannot resolve local paths.

- Public readers could not navigate from repo root to **Executed / Waived** GA language and v1.4 evidence without spelunking.

- No dedicated **`v1.5-MILESTONE-AUDIT.md`** — closure relied on **5/5** requirements + phase summaries.
