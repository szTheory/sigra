## Cross-Phase Integration Findings

### INT-01 · CRITICAL · Generated router does not mount user-operations routes

**File:** `priv/templates/sigra.install/admin/router_injection.ex`
**Affected:** USER-01..05, ADMIN-01, VFY-01
**Consequence:** Freshly generated host 404s on every user-ops route. Admin landing page redirects to `/admin/users`, which is unrouted.
**Fix:** Mirror `test/example/lib/example_web/router.ex:237-272` — mount `UsersIndexLive` and `UserShowLive` in both global and organization-scoped `live_session` blocks.

### INT-02 · CRITICAL · Generated installer does not emit ImpersonationController

**Files:** `priv/templates/sigra.install/admin/router_injection.ex` (references `<%= web_module %>.Admin.ImpersonationController` in 3 places); `lib/sigra/install/features/admin.ex:26-35` (`files/1` does not list it); template file does not exist.
**Affected:** IMPR-01, IMPR-02, IMPR-03, IMPR-05, ADMIN-01, VFY-01
**Consequence:** Generated host either fails to compile or 500s at first impersonation POST. Controller only exists at `test/example/lib/example_web/controllers/admin/impersonation_controller.ex` (example-app scope).
**Fix:** Create `priv/templates/sigra.install/admin/impersonation_controller.ex` from the example controller; add it to `Sigra.Install.Features.Admin.files/1`; add a generator test asserting emission.

### INT-03 · CRITICAL · Orphaned audit_export_controller template

**Files:** `priv/templates/sigra.install/admin/audit_export_controller.ex` exists as a full EEx template but is NOT in `Sigra.Install.Features.Admin.files/1` emission list. Router template references it.
**Affected:** AUD-04, ADMIN-01, VFY-01
**Consequence:** Generated host cannot serve CSV exports. Template wrote once but never wired to emission list.
**Fix:** Single-line add to `files/1` with the target host path; add generator test asserting emission.

### INT-04 · WARNING · Generated admin_shell Users nav is dead text

**File:** `priv/templates/sigra.install/admin/components/admin_shell.ex:67`
**Affected:** USER-01, USER-05, ADMIN-05
**Consequence:** Even after INT-01 is fixed, operators would have no visible path to user-ops from the shell. Missing top-bar scope-switch link and mobile bottom-nav entry too.
**Fix:** Port `users_link/1` helper and nav entries from `test/example/lib/example_web/components/admin_shell.ex:52-60,98-102`.

### INT-05 · INFO · Phase 28 recent-audit preview bypasses Phase 30 Presenter

**File:** `lib/sigra/admin/users/detail.ex:58-75`; `lib/sigra/admin/live/user_show_live.ex:207-213`
**Affected:** USER-03, AUD-03
**Consequence:** Impersonation rows in user-detail preview show `admin.impersonation.start` raw instead of the "Impersonation" badge and actor-summary label that Phase 30's explorer renders. Minor UX inconsistency; "View full audit" link still works.
**Fix:** Either pipe through `Presenter.present/2` or document the intentional preview minimalism in a decision note.
