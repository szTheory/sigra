## Tech Debt and Lessons

Phase 248's 2026-10-10 validation records 11 passing local checks, complete Wave 0, current protected-environment secret names/policies, exact-head candidate CI, and a hosted success receipt. It correctly leaves Nyquist partial because no eligible hosted failure/cancellation receipt exists. Do not rerun `$gsd-validate-phase 248` before new hosted evidence arrives.

The recurring evidence trap is snapshot drift: setup and verifier files can lag live environment configuration; a terminal acceptance can advance after a phase verifier; and a passing acceptance on a scoped evidence ref can coexist with an older blocked acceptance in the main working tree. Closeout automation should bind every report to immutable source/ref identities and automatically mark verifiers stale when their evidence inputs change. The safe AUTO-02 probe must use a non-publishing canary with no publish credentials; never interrupt a production release to manufacture failure/cancellation evidence. These prevention lessons are already recorded in `.planning/METHODOLOGY.md`.
