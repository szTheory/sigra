## Finding Inventory

### Cross-page asymmetries (same job → same component violations)

These findings recur across surfaces and represent the highest-value remediation targets:

1. **Applied chips inside vs outside form** — chips render INSIDE the `<form>` on `users_index_live.ex:107-114` (canonical GET-form contract) but OUTSIDE the form on `audit_index_live.ex:142-149` and `audit_user_live.ex:163-172`. Wave-2 remediation: move chips inside the form on both audit pages.

2. **scope_ribbon position before vs after `<header>`** — renders BEFORE `<header>` on `user_show_live.ex:44`, `user_sessions_live.ex:104`, `audit_user_live.ex:67` (entity-detail pages), but AFTER `</header>` on `audit_index_live.ex:56` (list page). Wave-2 remediation: align audit-index to before-header, or document after-header as the list-page canonical archetype (waiver).

3. **H1 entity-name vs page-type** — sibling entity-detail pages use the entity's name as H1 (`user_show_live.ex:48`, `audit_user_live.ex:71`) but `user_sessions_live.ex:108` uses the literal "Sessions". Wave-2 remediation: update H1 to user's name/email.

### Verbosity / positive-confirmation noise

4. **"All clear" bare notice** — both `index_live.ex:52` and `organization_live.ex:69` render the notice component with tone=:ok and bare "All clear" text on zero-risk state. Wave-2 remediation: tighten copy to "No users need review" / "No members need review".

5. **Sessions count duplicated** — `user_show_live.ex:54-58` (header summary-facts dl) repeats the same session count shown in the Sessions card sub-heading at `:84`. Wave-2 remediation: remove the session count from the header dl.

### Component divergence

6. **Bare `<p>` empty-states** — `organization_live.ex:95` and `:117` use bare `<p class="sg-section-copy">` paragraphs instead of the canonical `<.empty_state>` component (components.ex:410). Wave-2 remediation: swap to `<.empty_state>`.

7. **scope_ribbon hardcoded literal** — `branding_live.ex:106` is the only page using a bare string literal for scope_ribbon copy instead of a `scope_copy/1` helper. Wave-2 remediation: add `scope_copy/1` to branding_live.ex.

### Copy/IA concerns

8. **Revoke copy "They can sign in again"** — `user_sessions_live.ex:205, :209` — undermines security-remediation posture. Wave-2 remediation: remove the reassurance clause. (Copy/IA only; no Tier-2 ratchet per D-08.)

9. **4 divergent empty_state copies** on user-show (`user_show_live.ex:115, :146, :182, :202`). Wave-2 remediation: harmonize phrasing register.
