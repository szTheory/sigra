## Shared Patterns

### Immutable graph, private mutation

Read-only assertions may consume prepared variants directly. Any install rerun, upgrade,
database migration, compile, or runtime server receives a private checkout and private
build directory. Variant manifests carry absolute path, captured stdout where applicable,
unique partition, and unique port. Shared writable Mix manifests, `_build`, databases,
symlinks, or hardlinks are prohibited.

### Fixed commands and fail-closed statuses

Sources: `test/support/install_fixture.ex:43-267`,
`scripts/ci/library-economics.sh:1-155`, and
`scripts/ci/library-economics.test.sh:1-186`.

Use argv arrays or repository-owned shell arrays. Capture and propagate the first child
failure after writing diagnostics. Never accept a caller executable, arbitrary cleanup
root, threshold override, or `eval` string.

### Timing boundary and authority

The complete graph construction, snapshot copies including fallback cost, and all six
receivers remain between `install_start` and `install_end` in
`scripts/ci/library-economics.sh:136-151`. Diagnostic phase timing explains cost only.
The unchanged independent verifier alone decides:

```text
max(ordinary_ms, install_scaffold_ms) * 1000
  <= min(ordinary_ms, install_scaffold_ms) * 2000
install_scaffold_ms <= ordinary_ms
```

### Exact-once behavioral coverage

The six live `:scaffold` files remain the canonical PR receiver universe. Optimization may
reuse setup, but it cannot delete JS wiring, opt-out, golden tree/stdout, idempotency,
compile, vault, migration, database, or runtime assertions.

### Deterministic two-worker failure direction

Use exactly two workers, not unrestricted ExUnit concurrency. A failure cancels remaining
work, returns nonzero, keeps the failed checkout for diagnosis, and cannot be converted to
green by successful cleanup or receipt writing.
