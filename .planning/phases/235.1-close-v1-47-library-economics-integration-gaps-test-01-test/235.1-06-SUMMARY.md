## Decisions Made

- Generated variants carry their own partition and port identities even when consumed read-only; mutating receivers additionally receive unique checkout identities and private build paths.
- Each private checkout points Mix at its checkout-owned copy of the compatible prepared `_build/dev`; no empty rebuild tree or shared writable build is introduced.
- Copy-on-write is attempted with platform-native copy cloning, with a measured ordinary-copy fallback. Both modes dereference source links and are rejected if writable hardlink or symlink state remains.
- The fixture receipt intentionally contains no verdict. Its exact phase keys and raw bound explain install cost, while `verify-library-economics.sh` remains the only admission authority.
- Generated dependencies are resolved once into a graph-owned read-only `shared_deps`; each checkout has no local deps copy, retains a private writable build, and receives only the validated graph path through `MIX_DEPS_PATH`.
- A graph-global monitor-backed scheduler caps aggregate receiver and checkout work at exactly two, releases leases on caller death, and permits safe reentrant helper calls.
