## ASVS posture

Level 1; blocking threshold high.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Raw refresh input → digest lookup | Untrusted opaque credential identifies persisted family state without plaintext storage. |
| Locked refresh row → family mutation | Serialized classification decides rotation or reuse revocation. |
| Transaction commit → returned credentials | Raw replacement/access credentials may leave the service only after durable success. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-244-23 | Repudiation | reuse/audit co-fate | high | mitigate | Commit reuse-driven family revoke and optional audit atomically before returning D-11 outcome. |
| T-244-24 | Information Disclosure | refresh persistence/rollback | high | mitigate | Store only digests and return no replacement credentials before successful commit. |
| T-244-25 | Denial of Service | concurrent test orchestration | low | accept | Use bounded explicit process/database barriers; test failure terminates with diagnostics and no sleeps. |
</threat_model>
