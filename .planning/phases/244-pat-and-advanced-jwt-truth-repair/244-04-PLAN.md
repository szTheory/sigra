## ASVS posture

## Trust Boundaries

| Boundary | Description |
|---|---|
| Encoded JWT → configured signer | Untrusted token bytes cross the cryptographic verification boundary. |
| Verified payload/header → Sigra identity facts | Registered claims become authenticated subject and scope metadata. |
| Host custom claims → issued token | Host extension data must not override server-owned security claims. |
