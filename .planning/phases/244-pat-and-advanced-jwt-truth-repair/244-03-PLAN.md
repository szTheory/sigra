## ASVS posture

Level 1; blocking threshold high.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser request → PAT management | CSRF/session/sudo gates protect credential lifecycle actions. |
| Current Scope → host delegate | Server-authenticated identity becomes the sole owner selector. |
| Generated host → library runtime | Emitted files and routes must compile and call the intended explicit verifier. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-244-09 | Elevation of Privilege | generated PAT routes/controller | high | mitigate | Enforce browser + authenticated + RequireSudo and derive owner from current_scope per D-03/D-04. |
| T-244-10 | Tampering | PAT scope params | high | mitigate | Offer configured scopes only and retain library validation per D-05. |
| T-244-11 | Information Disclosure | PAT responses | high | mitigate | Return raw token only once on create and normalize foreign/absent revoke. |
| T-244-12 | Spoofing | fresh API request pipeline | high | mitigate | Runtime smoke authenticates through FetchAPIToken and asserts JWT/FetchBearer residue is absent. |
</threat_model>
