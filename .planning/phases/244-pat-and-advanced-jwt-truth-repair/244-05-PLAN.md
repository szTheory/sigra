## Trust Boundaries

| Boundary | Description |
|---|---|
| Host policy → JWT issuance delegate | Trusted host code selects subject and authority scopes. |
| Generated config → JWT verifier | Generated alg/type/issuer/audience policy controls acceptance. |
| Installer output → fresh host runtime | Missing or leaked cross-feature artifacts alter the host attack surface. |
