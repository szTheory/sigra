# Phase 208.1 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> **The arbiter of "done" is the real CI required check `Example Playwright smoke (full lifecycle)`, NOT local green.** Local Playwright diverges from CI in known ways (font metrics, JS bundle drift, compile-time PORT, disposable-PG). Local green is necessary but not sufficient.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Playwright (`@playwright/test`) in `test/example/priv/playwright/` |
| **Config file** | `test/example/priv/playwright/playwright.config.ts` (projects: chromium, mobile, admin-design-{chromium,mobile,dark}, admin-checkpoints-{chromium,mobile,dark}, demo-showcase-chromium) |
| **Quick run command** | `cd test/example/priv/playwright && npx playwright test <spec> --project=chromium` (server pre-booted on `SIGRA_EXAMPLE_URL`) |
| **Full suite command** | The 5 required-check seams — locally via the enumeration recipe (RESEARCH §"Local full-suite enumeration recipe"); authoritatively via the CI required check |
| **Estimated runtime** | ~local: several min full enumeration; CI required check is the arbiter |

---

## Sampling Rate

- **After every task commit:** Run the single affected spec group on chromium (fast pre-filter).
- **After every plan wave:** Run the full enumeration harness (all 5 groups + checkpoints) locally on :4011 against Docker PG, discarding snapshot churn.
- **Before `/gsd-verify-work`:** A real CI run of `Example Playwright smoke (full lifecycle)` is GREEN (dispatched via `wip/recapture-trigger`), and the 12 board-cfg baselines are committed via the recapture PR.
- **Max feedback latency:** local quick run ~seconds-to-minutes per group; CI gate is the final arbiter.
