<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| org admin browser -> generated admin LiveView | Untrusted form input and operator actions drive enterprise connection updates and activation attempts. |
| generated admin LiveView -> enterprise connection context | UI must relay, not reinterpret, security-critical validation truth from Plan 01 APIs. |
| docs/copy -> operator expectations | Misleading copy could cause unsafe assumptions about active status or milestone scope. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-122-04 | S | Org-admin route mounting | mitigate | Keep the page only inside the existing `:admin_organization` live session and generator-owned org-admin route block so only authorized org admins can reach it. |
| T-122-05 | T | Lifecycle/status UI | mitigate | Render lifecycle badges and failure copy directly from persisted status/error fields; never infer `active` from field presence or save success alone. |
| T-122-06 | R | Docs and operator copy | mitigate | Document non-goals and setup-only scope explicitly so operators do not assume routing, JIT, or enforcement shipped in Phase 122. |
</threat_model>
