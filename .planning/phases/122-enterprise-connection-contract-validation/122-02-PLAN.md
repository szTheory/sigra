<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| library lifecycle -> generated-host UI | If the UI computes active state from field presence or local assumptions, operator truth diverges from the library contract. |
| org owner route -> unauthorized viewer | If the new surface is not constrained to the existing organization settings path and owner rules, non-owners may enumerate enterprise setup state. |
| template source -> example/golden output | If template and example app diverge, Phase 122 can appear complete locally while shipping broken installer output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-122-05 | T | generated-host status UI | mitigate | Render only persisted `status` and safe `last_validation_error` values from the library API. |
| T-122-06 | E | org settings access | mitigate | Reuse the existing owner-gated `OrganizationSettingsLive` path and wrapper contract. |
| T-122-07 | R | template/example drift | mitigate | Update both template and example app, then lock them with install feature and golden tests. |
</threat_model>
