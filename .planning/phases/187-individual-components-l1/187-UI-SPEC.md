## Design System

| Property | Value |
|----------|-------|
| Tool | none — preserve the hand-authored `sg-*` cascade-layer/BEM admin design system |
| Preset | not applicable |
| Component library | Phoenix LiveView function components in `Sigra.Admin.Components`; no Radix/Base UI/shadcn |

The 13 L1 components are: `stat`, `stat_link`, `task_card`, `summary_chip`, `applied_chip`, `empty_state`, `page_back`, `scope_ribbon`, `notice`, `notice_link`, `field_help`, `skeleton`, `audit_row`.

Component visual/state CSS must ship from `priv/templates/sigra.install/admin/sigra_admin.css` inside `@layer sg-components`. Any migrated `sg-*` component rules must be removed from `test/example/priv/static/assets/css/app.css`; app.css keeps example-only `vt-*` glue. Keep these three parity surfaces byte-aligned: canonical template, example mirror, and install golden fixture.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | `--sg-space-1` / 4px | Icon gaps, inline padding |
| sm | `--sg-space-2` / 8px | Compact element spacing |
| md | `--sg-space-4` / 16px | Default element spacing and card padding |
| lg | `--sg-space-6` / 24px | Section-internal rhythm |
| xl | `--sg-space-8` / 32px | Major layout gaps |
| 2xl | `--sg-space-12` / 48px | Page-level spacing |
| 3xl | `--sg-container-max` governs wide layout; do not introduce a new 64px token in Phase 187 | Page width/major spacing remains per existing layout tokens |

Exceptions: Existing ratified component sizing tokens may continue: `--sg-space-3` 12px, `--sg-space-5` 20px, `--sg-space-7` 28px, `--sg-space-10` 40px, `--sg-pill-*`, `--sg-control-*`, and `--sg-code-pad-y`. Interactive touch targets use `--sg-control-md` 44px or larger where the control is not intentionally compact.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | `--sg-text-base` / 16px | `--sg-weight-regular` / 450 | `--sg-leading-normal` / 1.5 |
| Label | `--sg-text-sm` / 14px | `--sg-weight-medium` / 600 | `--sg-leading-snug` / 1.3 |
| Heading | `--sg-text-lg` / ~23px | `--sg-weight-semibold` / 700 | `--sg-leading-tight` / 1.1 |
| Display | `--sg-text-xl` / 30px | `--sg-weight-bold` / 800 | `--sg-leading-tight` / 1.1 |

Component internals may use existing dense tokens (`--sg-text-2xs`, `--sg-text-xs`, `--sg-text-md`) only where already specified by `admin-design-contract.md` or `admin-token-reference.md` for audit rows, captions, metric labels, and compact chips. Do not scale font size with viewport width, except the existing ratified `--sg-text-2xl` dashboard display token.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `--sg-color-subtle` light `#f6f5f2`, dark `#171614` | Admin canvas/background |
| Secondary (30%) | `--sg-color-panel` light `#ffffff`, dark `#1f1d1a`; `--sg-color-panel-alt` for alternate rows | Cards, component boards, panels, rows, help panels |
| Accent (10%) | `--sg-color-brand` `#c2410c`; dark text-on-soft uses `--sg-color-brand-strong` `#fdba74` | Sigra identity, primary actions, selected states, ownership-boundary emphasis, focus ring tint |
| Destructive | `--sg-color-risk` light `#b42318`, dark `#f8a39c` | Destructive actions, error/risk notices, danger states only |

Accent reserved for: Rail Accent identity assets, `.sg-btn--primary`, selected/active filter or chip states, focus rings, inline notice actions, ownership/scope emphasis, and brand-soft component states. Do not use ember for every heading, icon, border, or decorative emphasis.

Status tones must pair color with text, border/icon/glyph/shape, or label. `ok`, `warn`, `risk`, and `info` use the existing semantic token pairs; color alone is insufficient.

Light, Dark, and System are mandatory. Explicit choices use `data-sg-admin-theme`; System follows `prefers-color-scheme`. No component rule may hard-code a raw color when a `--sg-*` token exists.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Review accounts` for risk-account notices; component examples should use verb-first labels such as `Manage users`, `View audit log`, `Open organization`, `Clear filter` |
| Empty state heading | `No users found` |
| Empty state body | `Try adjusting your filters.` |
| Error state | `Unable to load component state. Refresh the page, then check the admin logs if it happens again.` |
| Destructive confirmation | No new destructive component behavior in Phase 187. Existing destructive action components must keep danger styling, require confirmation at the page/flow layer, and use copy in the form `Confirm {action}` plus a concrete consequence. |

Component-local copy must stay terse, useful, and operator-calibrated. Use one term per concept, but defer the system-wide glossary and voice sweep to Phase 191. Notices should state the condition and next action in one sentence; `notice_link` is for an inline next step, not a button row. `field_help` must answer what the field affects; it must not contain controls or links.

## Component Interaction Contract

| Component | Required visual/interaction contract |
|-----------|--------------------------------------|
| `stat` | Static read-only KPI. No hover lift, no focus state, no navigation affordance. Uses `sg-metric*` styling and definition-list semantics. |
| `stat_link` | Real link. Hover may lift with `box-shadow`; focus-visible uses ring only; active state must be visible. Link text is label plus value. |
| `task_card` | Article with one CTA link. Pointer hover may translate `-1px` and lift; keyboard focus appears on the CTA, not the whole card unless the card itself becomes interactive. |
| `summary_chip` | Non-interactive metric/posture chip. Optional help opens on hover/focus/touch with tooltip semantics; no visible `?` trigger; no counter animation. |
| `applied_chip` | Active filter indicator with explicit remove link. Remove affordance has `aria-label="Remove filter {label}"`; no animation on filter apply/remove beyond tone transition. |
| `empty_state` | Static zero-data placeholder with dashed treatment and title/body copy. Not used for loading or errors. |
| `page_back` | Ghost small button/link for leaf return paths only. Includes visible arrow glyph hidden from assistive tech and descriptive text. |
| `scope_ribbon` | Static body scope indicator. No animation and no navigation role. Distinct from shell `sg-scope-pill`. |
| `notice` | Block-level contextual alert with `data-tone`. No live-region role unless the call site is post-load dynamic. Inline next-step links only. |
| `notice_link` | Native underlined inline link inside `notice`. Hover/focus/active states affect text/underline/ring only, not filled button styling. |
| `field_help` | Native button trigger with `aria-controls`, `aria-describedby`, `aria-expanded`; tooltip panel uses `role="tooltip"` and toggles on hover, focus, click/tap, Escape, and outside click. |
| `skeleton` | Loading placeholder matching the replaced content shape. Container owns `aria-busy`; skeleton itself is decorative. Reduced motion leaves a static block. |
| `audit_row` | Audit event card using `sg-list-row`, status pill tone, actor summary, timestamp, and optional codes. Tone must be visible beyond color alone. |

Every applicable interactive component must render visually distinct default, hover, focus-visible, active, disabled, loading, empty, and error states in the `/admin/_design` board matrix. Disabled states must be inert. Pointer hover must be gated with `@media (hover: hover) and (pointer: fine)`.

Motion uses exact-property transitions only. Never use `transition: all`. Prefer transform, opacity, color, background-color, box-shadow, and underline-color. Keyboard-frequent paths are not animated. `@media (prefers-reduced-motion: reduce)` must strip movement.
