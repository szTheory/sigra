   - `generate(count \\ 8)` -- returns list of `{formatted_string, sha256_hex_hash}` tuples. Uses `:crypto.strong_rand_bytes(4)`, `rem(100_000_000)`, pad to 8 digits, format as "XXXX-XXXX". Hash is `:crypto.hash(:sha256, normalized_digits) |> Base.encode16(case: :lower)`. Per D-12, D-13.

Returns `{:ok, :consumed}` if {1, _} or `{:error, :invalid_backup_code}` if {0, _}. Per D-16.
   - `remaining_count(repo, backup_code_schema, user_id)` -- counts where `is_nil(used_at)` for user.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client -> MFA verify endpoint | User-submitted TOTP/backup codes cross trust boundary |
| Trust cookie -> server | HMAC-signed cookie from client, must be verified |
| Session -> MFA gate | mfa_pending session must not access protected routes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Spoofing | TOTP verification | mitigate | Replay prevention via last_verified_step tracking (D-41) |
| T-06-02 | Tampering | Trust cookie | mitigate | HMAC signing via Plug.Crypto.sign with secret_key_base (D-46) |
| T-06-03 | Repudiation | MFA operations | mitigate | Telemetry events for all MFA operations (Plan 03) |
| T-06-04 | Information Disclosure | Backup codes | mitigate | SHA-256 hashed storage, never retrievable after display (D-13, D-20) |
| T-06-05 | Denial of Service | MFA lockout | mitigate | Per-user lockout counter on DB, not per-session (D-31), threshold 5 attempts (D-19) |
| T-06-06 | Elevation of Privilege | mfa_pending bypass | mitigate | RequireMFA plug blocks all routes except /users/mfa and /users/log_out (Plan 02, D-24) |
| T-06-07 | Spoofing | Trust cookie user_id mismatch | mitigate | Verify user_id + epoch in cookie matches current authenticated user (Pitfall 6) |
| T-06-08 | Information Disclosure | TOTP secret in DB | mitigate | cloak_ecto AES-256-GCM encryption at rest (D-09, MFA-09) |
| T-06-09 | Elevation of Privilege | Session fixation on MFA complete | mitigate | Token rotated on MFA completion (D-25, Plan 02) |
</threat_model>
