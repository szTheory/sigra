1. **lib/sigra/testing.ex**: Add MFA testing helpers:

   - `setup_totp(user, opts \\ [])` -- Creates a fully enrolled MFA credential for the user. Generates real TOTP secret, creates credential in DB, generates and stores backup codes. Returns `%{secret: raw_secret, credential: credential, backup_codes: [formatted_codes]}`. Per D-92.

   - `generate_totp_code(secret)` -- Generates a real valid TOTP code for the given raw secret using `NimbleTOTP.verification_code(secret)`. Returns the 6-digit string. Per D-92, D-95.

   - `create_backup_codes(user, opts \\ [])` -- Generates backup codes for user (calls `Sigra.MFA.BackupCodes.generate/1`), stores hashes in DB. Returns list of raw formatted codes. Per D-92.

   - `bypass_mfa(user)` -- Marks user's session as MFA-completed without requiring code entry. Sets session type to `:standard`. For tests that don't care about MFA flow. Per D-92.

   - `simulate_mfa_lockout(user)` -- Sets failed_attempts to threshold and locked_until to 15 minutes from now on user's MFA credential. Per D-92.

   - `assert_mfa_enabled(user)` -- Asserts that user has an MFA credential with non-nil enabled_at. Raises on failure. Per D-92.

   - `assert_mfa_disabled(user)` -- Asserts that user has no MFA credential. Raises on failure. Per D-92.

   - `trust_browser(conn, user)` -- Sets the `_sigra_mfa_trust` cookie on the conn for the given user, simulating a trusted browser. Per D-92.

   Update existing `log_in_user/2` to accept `mfa: :bypass` option. When set, if the user has MFA enrolled, the session is created as `:standard` (not `:mfa_pending`). Per D-93.

2. **lib/sigra/workers/token_cleanup.ex**: Extend the existing Oban cron worker to also clean up expired `mfa_pending` sessions:
   - Query for sessions with `type = :mfa_pending` and `inserted_at < now - pending_timeout`.
   - Delete matched sessions.
   - Emit `[:sigra, :mfa, :pending_expired]` telemetry event for each expired session.
   Per D-26, D-32.
