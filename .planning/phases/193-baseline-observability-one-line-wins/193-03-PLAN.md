| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → third-party actions | All `uses:` actions cross a supply-chain boundary; pins must hold |
| PR metadata (`github.event.*`) → summary `run:` shell | Untrusted input MUST NOT reach a summary shell command |
| GITHUB_TOKEN scope → workflow steps | Token permission boundary; must stay least-privilege |
