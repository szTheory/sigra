## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| impersonating request -> generated API-token mutations | A support session must not mint or revoke API credentials while acting as another user |
| generated controller -> generated wrapper | The generated controller must delegate through one guarded wrapper seam instead of ad hoc conditionals |
| generated wrapper -> Sigra auth runtime | API-token mutations must inherit the same impersonation restriction semantics as other sensitive actions |
