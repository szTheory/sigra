## Trust Boundaries

| Boundary | Description |
|---|---|
| signed browser continuation → database | Stateless signed input crosses into a unique digest-backed atomic consumption record. |
| PostgreSQL transaction → callback response | Raw hosted code may leave only after the digest-bound row commits. |
| replay/concurrency → approval facade | Duplicate signed inputs must collapse to one bounded failure without identity or policy detail. |
