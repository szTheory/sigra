## Shared Patterns

### Absolute GitHub URL for Out-of-Tree Docs Links
**Source:** `docs/ga-evidence.md` lines 11–13
**Apply to:** Any `docs/*.md` file that needs to link to `.planning/` artifacts
```markdown
https://github.com/szTheory/sigra/blob/main/<path-relative-to-repo-root>
```
ExDoc treats absolute URLs as external links and skips resolution — no `skip_undefined_reference_warnings_on` entry required.

### mix.exs Suppression Comment Block Convention
**Source:** `mix.exs` lines 168–178
**Apply to:** Any future `skip_undefined_reference_warnings_on` entries
```elixir
        # Phase NNN: one-line rationale for why this file needs suppression.
        "path/to/file.md"
```
When the root cause is fixed (link repaired, moduledoc added, etc.), remove both the comment and the entry together.
