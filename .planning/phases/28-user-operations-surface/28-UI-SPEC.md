## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline status separators, badge padding adjustments |
| sm | 8px | Compact chip spacing, card internals, inline action gaps |
| md | 16px | Default row/card padding, form control spacing, section internals |
| lg | 24px | List header spacing, drawer/sheet padding, grouped filter spacing |
| xl | 32px | Desktop split gaps between filter rail and content, detail section spacing |
| 2xl | 48px | Major section breaks on detail pages |
| 3xl | 64px | Top-level page spacing on wide desktop only |

Exceptions: 44px minimum touch target for icon-only buttons, overflow menus, pagination taps, and mobile session actions.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--color-base-100)`; light `oklch(98% 0 0)`, dark `oklch(30.33% 0.016 252.42)` | Page background, list canvas, detail canvas, drawer background |
| Secondary (30%) | `var(--color-base-200)`; light `oklch(96% 0.001 286.375)`, dark `oklch(25.26% 0.014 253.1)` | Cards, sticky shell bars, filter trays, section containers, mobile cards |
| Accent (10%) | `var(--color-primary)`; light `oklch(70% 0.213 47.604)`, dark `oklch(58% 0.233 277.117)` | Active navigation, primary CTA, selected quick filters, active pagination state, high-priority status emphasis |
| Destructive | `var(--color-error)`; light/dark `oklch(58% 0.253 17.585)` | Revoke session actions, destructive confirmations, destructive badges only |

Accent reserved for: primary list/detail CTA, currently selected filter chips, active nav destination, active page control, and the single most important status/action on a screen. Do not use accent on every link, every badge, or neutral metadata.

---

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | Open user |
| Empty state heading | No users match this view |
| Empty state body | Try a different search or clear one or more filters to widen the result set. |
| Error state | We couldn't load this user data. Refresh the page, then try again. If the problem continues, return to the user list and retry from the current scope. |
| Destructive confirmation | Revoke session: Revoke this session for {user_email} in {scope_label}? The user will need to sign in again. Revoke all sessions: Revoke every active session for {user_email} in {scope_label}? This signs them out everywhere. |
