     - Call `resolve_config()` to get repo, email_module, mailer
     - Look up user: `repo.get(user_schema, args["user_id"])` -- but we don't have user_schema in config yet. Instead, use `repo.get_by(user_schema, id: args["user_id"])`. Actually simpler: add `:user_schema` to the config keys too. OR use `Application.fetch_env!(:sigra, :user_schema)`.
     - If user is nil, return `{:error, :user_not_found}` (Oban will not retry on this -- use `{:cancel, :user_not_found}` to tell Oban to not retry)

     - On `{:ok, _}` return `{:ok, :delivered}`
     - On `{:error, reason}` return `{:error, reason}` (Oban will retry per backoff)
     - Wrap the entire operation in the existing `Telemetry.span` call
