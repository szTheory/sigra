<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Smoke seed → impersonation | Target user must never receive platform-admin bit or org-admin role; otherwise impersonation test proves nothing. |
| CSV export → data leakage | Assertions must use **global** admin session and must not weaken unknown-org / org-scope bash probes. |
| Playwright `request` vs page | Export test must send cookies from logged-in session; avoid unauthenticated GET that passes with empty CSV. |

## Threats

| ID | Severity | Threat | Mitigation |
|----|----------|--------|------------|
| T-34-01 | high | Third user accidentally granted admin routes | Seed only `register_user` + `confirm` for target email; no membership inserts. |
| T-34-02 | high | CSV export probed without session | Use authenticated `page.request` with storage state from `logIn` or `page.goto` export after login. |
| T-34-03 | medium | `--test` slice skips bash probes | Keep parity block **above** `case` (no refactor that moves Playwright before `GEN_PARITY_FAIL` checks). |

## Security Notes

- Keep unauthenticated POST impersonation probe semantics: **non-5xx**, not success (`admin-acceptance-smoke.sh` commentary).
- Strictly reject **200** on unknown-org audit probe in bash block.

Block on: high
