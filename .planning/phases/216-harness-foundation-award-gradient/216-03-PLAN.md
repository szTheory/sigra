<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| captured outerHTML → render_sha256 | Untrusted, per-request-volatile HTML is reduced to a committed content hash |
| bundle files → downstream guards | The gitignored bundle tree is the evidence the stale-render + anchor guards trust |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-216-03-REPRO | Tampering | render_sha256 reproducibility | high | mitigate | Allowlist canonicalization strips ALL per-request volatile attrs (data-phx-*/nonce/?vsn=/digest) + sorts attrs/classes + normalizes whitespace + excludes raw geometry; the determinism self-test proves volatile mutations are SHA-invariant (Pitfall 2). A non-reproducible SHA would let a benign re-run masquerade as a change (or hide a real one). |
| T-216-03-PARSE | Tampering | parse5 over untrusted HTML | low | mitigate | HTML is parsed with the spec-compliant structural parser parse5, never `eval`/regex; the string is already-hydrated so no JS execution (V5 Input Validation). |
| T-216-03-COLLIDE | Tampering | cross-commit bundle collision | medium | mitigate | Bundles are keyed top-level on app_git_sha so a stale bundle from another commit can never be read as the current render (feeds the stale-render guard, Plan 06). |
</threat_model>
