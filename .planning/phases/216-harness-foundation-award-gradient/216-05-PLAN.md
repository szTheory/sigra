<objective>
Build the award verify-then-climb guard (D-20) — the structural cure for the manual era's optimistically-flipped ledger cells. It enforces that an award band can only rise when backed by a fresh render (`verified_at_sha` changed), that the band is always the derived `min()` of the 4-axis vector, that every raised axis is `rendered:true` with an `evidence_ref` that resolves to a real probe/test id, and that no axis decreases vs merge-base. Prose "reviewed —" can no longer raise a band; only a resolvable probe id can.

Purpose: RATCHET-01's anti-gaming invariant lives entirely in this guard. Isolating it (net-new node/JSON mechanism, no repo analog) with a self-test covering all five FAIL conditions keeps the merge-blocking signal trustworthy.

Output: `award-guard.mjs`, its self-test, and the shared probe-id constant module.
</objective>
