## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local commit → GitHub PR run | The external runner must test the exact frozen object, not a nearby or earlier SHA. |
| GitHub Actions API → evidence receipt | API payloads, pagination, null conclusions, reruns, and rate limits can produce incomplete or misleading evidence. |
| generated build cache → local ExUnit | Optional-dependency compilation order can leave the Sigra forwarder absent until a fresh test build. |
| receipt → public PR comment | The comment is permanent public evidence and must contain CI metadata only. |
