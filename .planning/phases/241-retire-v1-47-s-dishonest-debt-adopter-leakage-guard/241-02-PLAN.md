### Decisions implemented by this plan

- **D-06:** only the **first three** tests are rewritten. The replacement derives the `library_tests*`
  job universe from the subject and asserts the count of `MIX_ENV=test mix ci` invocations across
  those job bodies is exactly 1, with no such job retaining a bare `mix test` — the invariant, not
  the screenshot. The hardcoded `@library_jobs` equality comparison is removed.
- **D-07:** the missing half was a substitutable subject. A function-resolved
  `SIGRA_CONTRACT_SUBJECT` override is added, mirroring `_lib.mjs`'s `subjectPath()` /
  `GSD_PROHIB_SUBJECT` contract, including its missing-subject-is-a-broken-run rule.
- **D-08:** the guard **stays in ExUnit**, inside `mix ci`'s existing `test --exclude scaffold` leg.
  Porting it to a `pNN-*.test.mjs` prohibition would move the alias guard out of `mix ci` and weaken
  the local gate. The RED is mechanized instead by a scripted `bash -c` run recorded in evidence.
- **D-09:** the `235-FAST-01-REMEDIATION.json` dependency is **retired** — the two receipt tests are
  deleted and the evidence file records that git history plus the `239`-style evidence files are the
  tamper record.
- **D-10:** the JSON **file itself stays**, because `scripts/ci/capture-fast-01-gap-closure.sh` and
  `phase_235_fast_01_gap_closure_contract_test.exs` both read it. Task 2 carries the helper-deletion
  trap that reds `compile --warnings-as-errors` if only the test blocks are removed.
</objective>
