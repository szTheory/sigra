  <action>
In `test/test_helper.exs`, insert a conditional `ExUnit.configure(exclude: [:upgrade])` block
BEFORE the existing `ExUnit.start()` call. The block must:

1. Check whether the phx_new 1.8.8 archive is installed by running `System.cmd("mix", ["archive.list"], stderr_to_stdout: true)` and checking if the output contains "phx_new-1.8.8"
2. If the archive is absent, call `ExUnit.configure(exclude: [:upgrade])` to skip the upgrade test
3. If the archive is present, do nothing (upgrade test runs normally)

The guard must NOT:
- Use a blanket `:postgres` exclusion (CLAUDE.md forbids this — the regular test DB is always available; we are only skipping tests that require the phx_new archive)
- Use an unconditional exclusion (CI has the archive installed — the test must run there)

Include an explanatory comment that makes the conditional-not-blanket requirement explicit, e.g.:
"Graceful preflight skip for UpgradeIntegrationTest (D-19) — shells out to mix phx.new, requires
phx_new 1.8.8 archive. CI installs the archive so the test runs there. Local dev without the archive
gets a clean skip. NOT a blanket :postgres exclusion — CLAUDE.md forbids that pattern."

Pattern (from PATTERNS.md):
```elixir
phx_new_ok? =
  case System.cmd("mix", ["archive.list"], stderr_to_stdout: true) do
    {output, 0} -> String.contains?(output, "phx_new-1.8.8")
    _ -> false
  end

unless phx_new_ok? do
  ExUnit.configure(exclude: [:upgrade])
end
```

Place this block before `ExUnit.start()`. The final file structure should be:
1. Existing comment block
2. (new) phx_new_ok? check + conditional configure
3. ExUnit.start()

After editing, run `mix test --seed 0 2>&1 | tail -20` locally (without phx_new 1.8.8) to confirm
zero spurious upgrade-test failures. The output should show the total test count with the upgrade
tests excluded and no error from the upgrade test itself.
