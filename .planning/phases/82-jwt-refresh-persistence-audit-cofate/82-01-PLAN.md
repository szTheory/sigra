<objective>
Implement **AUD-19-01** and **AUD-19-02**: single transactional boundary for JWT refresh-token **`user_tokens`** writes and **`api.jwt_refresh`** / **`api.jwt_refresh_reuse`** when audit is enabled, per **82-CONTEXT.md** D-82-01..D-82-03.
</objective>

<threat_model>
| ID | STRIDE | Finding | Severity | Mitigation in plan |
|----|--------|---------|----------|-------------------|
| T-82-01 | Repudiation | Refresh rotated in DB without durable **`api.jwt_refresh`** row | high | One **`Repo.transaction`** wrapping persistence **`Multi`** + **`append_api_token_jwt_audit_to_multi`** |
| T-82-02 | Tampering | Partial **`user_tokens`** state after aborted audit | high | **`Multi` rollback** on any step failure; return **`{:error, :jwt_refresh_aborted}`** |
| T-82-03 | Information disclosure | Telemetry claims reuse before DB commits reuse handling | medium | Move **`[:sigra, :jwt, :refresh_reuse_detected]`** to post-commit success branch (D-82-03) |
</threat_model>
