**2. Create migration template `priv/templates/sigra.install/organizations/migration.exs`:**

One migration file, FK-ordered: organizations -> memberships -> invitations. Adapter-branched following the exact pattern in `core/migration.exs`.

Organizations table:
- `id :binary_id, primary_key: true`
- `name :string, null: false` (max 255)
- `slug` -- PostgreSQL: `:citext, null: false`; MySQL/SQLite: `:string, null: false, size: 63`
- `deleted_at :utc_datetime`
- `timestamps(type: :utc_datetime)`
- Index: PostgreSQL partial unique on `[:slug]` with `where: "deleted_at IS NULL"`; MySQL/SQLite plain unique on `[:slug]` (no partial index support, application-level handles soft-delete reclamation)

Organization memberships table:
- `id :binary_id, primary_key: true`
- `role :string, null: false, default: "member"` (Ecto.Enum maps at app layer)
- `organization_id references(:organizations, type: :binary_id, on_delete: :delete_all), null: false`
- `user_id references(:<%= table_name %>, type: :binary_id, on_delete: :delete_all), null: false`
- `timestamps(type: :utc_datetime)`
- Unique index on `[:user_id, :organization_id]`
- Index on `[:organization_id]`

Organization invitations table:
- `id :binary_id, primary_key: true`
- `email` -- PostgreSQL: `:citext, null: false`; MySQL/SQLite: `:string, null: false, size: 160`
- `role :string, null: false, default: "member"`
- `hashed_token :binary`
- `accepted_at :utc_datetime`
- `revoked_at :utc_datetime`
- `expires_at :utc_datetime, null: false`
- `organization_id references(:organizations, type: :binary_id, on_delete: :delete_all), null: false`
- `invited_by_id references(:<%= table_name %>, type: :binary_id, on_delete: :nilify_all)`
- `accepted_by_id references(:<%= table_name %>, type: :binary_id, on_delete: :nilify_all)`
- `timestamps(type: :utc_datetime)`
- PostgreSQL partial unique on `[:organization_id, :email]` with `where: "accepted_at IS NULL AND revoked_at IS NULL"`
- MySQL/SQLite: unique index on `[:organization_id, :email, :accepted_at, :revoked_at]`
- Index on `[:hashed_token]`

Use `<%= table_name %>` for the users table reference (same binding as core migration). Use `<%= if adapter == :postgres do %>` branching for citext/partial indexes.
