| 2 | `--sg-space-2` | 8px (0.5rem) | Tight intra-component gap (button icon-to-text) |

The following three tokens are part of the shipped `sg-*` vocabulary and were ratified
before Phase 190. They are valid 4px-grid multiples but fall outside the checker's standard
set. They are documented here as exceptions — Phase 190 makes no new spacing decision for
these values; flow specs assert against them as-shipped.

| Token | CSS Custom Property | Value | Justification |
|-------|--------------------|----|-------|
| 3 | `--sg-space-3` | 12px (0.75rem) | Pre-ratified `sg-*` token (4px grid); compact padding within list rows and small cards |
| 5 | `--sg-space-5` | 20px (1.25rem) | Pre-ratified `sg-*` token (4px grid); comfortable spacing between sibling controls |
| 10 | `--sg-space-10` | 40px (2.5rem) | Pre-ratified `sg-*` token (4px grid); between grouped top-level sections |

Control height relevant for touch targets: `--sg-control-md` = 44px (meets WCAG 2.5.8 minimum target size). All keyboard-reachable controls in the flow specs must meet this minimum.

## Color

Source: `admin-token-reference.md`. All values are `sg-*` CSS custom properties with Light/Dark overrides.

| Role | CSS Token | Light Value | Dark Value | Usage |
|------|-----------|-------------|------------|-------|
| Dominant (60%) — page canvas | `--sg-color-subtle` | `#f6f5f2` | `#171614` | Page background; warm tint differentiates admin from plain-white hosts |
| Secondary (30%) — card/nav surfaces | `--sg-color-panel` | `#ffffff` | `#1f1d1a` | Card, modal, and nav surfaces on top of the subtle page background |
| Accent (10%) — brand ember | `--sg-color-brand` | `#c2410c` | `#c2410c` | Primary interactive labels, ownership emphasis, focus indicators |
| Destructive | `--sg-color-risk` | `#b42318` | `#f8a39c` | Destructive actions and error states only |

**Accent reserved for (explicit list):**
- Primary action buttons (`sg-btn--primary`)
- Selected/active navigation states
- Ownership-boundary emphasis (scope indicators)
- Focus ring color (`--sg-color-brand` tint)
- Applied filter chip highlight
- Impersonation banner brand elements

**Accent is NOT used for:** every heading, every icon, decorative backgrounds, secondary buttons, or informational notices.

**Primary visual anchor:** The scope ribbon + primary CTA cluster at the top of the users list is the focal point of the main admin screen — it establishes the operator's scope context and surfaces the primary next action before any list content.

**Semantic status colors (referenced in flow assertions):**

| Role | Light | Dark | Reserved For |
|------|-------|------|-------------|
| `--sg-color-ok` | `#176b43` | `#5dd1a0` | Confirmed/active/positive states; "All clear" alarm |
| `--sg-color-warn` | `#a15c00` | `#f5c451` | Pending review, advisory notices |
| `--sg-color-risk` | `#b42318` | `#f8a39c` | Risk alerts, destructive actions, error states |
| `--sg-color-info` | `#1d4ed8` | `#9db8f5` | Informational notices, contextual help |

**Dark AA note:** `--sg-color-brand-strong` is `#fdba74` (ember-300) in dark mode — lightened from `#9a3412` to clear WCAG AA on dark brand-soft surfaces. Ratified in v1.34; do not revert.

**Theme persistence contract (FLOW-03 assertion target):**
- Explicit choice stored in `localStorage['sigra.admin.theme']`
- Root attribute: `data-sg-admin-theme` on `<html>`
- Shell attribute: `data-theme` on `.sg-admin-shell`
- No-flash: `applyTheme` script in `<head>` is synchronous (not `async`/`defer`)
- System mode: removes override attribute, follows `prefers-color-scheme`

## Interaction Contract

> This section is specific to Phase 190 and supplements the standard template sections.
> It defines the behavioral assertions the Playwright flow specs must validate against
> the already-shipped admin UI.

### Keyboard Operability (FLOW-02)

All three operator flows must be fully keyboard-operable. Assertion strategy:

| Behavior | Assertion Method |
|----------|-----------------|
| Tab through interactive elements | `keyboard.press('Tab')` + `toBeFocused()` (auto-retrying) |
| Focus-visible ring after keyboard Tab | Assert `toBeFocused()` only AFTER a keyboard Tab, never after a click (click suppresses `:focus-visible`) |
| Focus containment in confirm dialog | Assert "focus still inside the dialog" invariant, not the exact element after a fixed Tab count |
| Focus return to trigger after dialog close | Assert focus returns to the trigger element after `sg-confirm-overlay` closes |
| Escape dismisses overlays | `keyboard.press('Escape')` + assert overlay gone + focus on trigger |
| Enter/Space activates buttons | `keyboard.press('Enter')` on focused button |

**WR-01 target element:** `[data-sg-confirm-cancel]` (not positional `focusables[0]`) — folded from 189-REVIEW.

**WR-02 sentinel:** `<body>` focus-return fallback when the trigger element is no longer in the DOM.

**WR-03 Escape guard:** `stopImmediatePropagation()` on the Escape handler to prevent co-resident document listeners from double-firing.

These three hardening items (`admin_hooks.js`) are in-scope for Phase 190 and trigger the three-surface byte-parity rule: canonical template + example mirror must stay byte-identical after changes.

### Reduced-Motion (FLOW-02)

| Behavior | Assertion Method |
|----------|-----------------|
| Set reduced motion context | `reducedMotion: 'reduce'` at **context/config level** (not per-page after `goto`) |
| Assert collapsed effect | Assert `transition-duration: 0s` / `animation-duration: 0s` on elements covered by `@media (prefers-reduced-motion: reduce)` guard (`sigra_admin.css:1467`) |
| Do not assert only `matchMedia().matches` | Verify the **CSS effect** is collapsed, not merely that the media query is set |

### Theme Persistence (FLOW-03)

| Behavior | Assertion Method |
|----------|-----------------|
| Attribute set correctly | `data-sg-admin-theme` on `<html>` + `data-theme` on `.sg-admin-shell` |
| localStorage persisted | `localStorage['sigra.admin.theme']` matches selected theme |
| Persists across LiveView navigation | Assert attribute unchanged after LiveView patch/navigate |
| Persists across `page.reload()` | Assert attribute correct immediately after reload |
| System flip without reload | Emulate `prefers-color-scheme` flip; assert attribute follows system without explicit reload |
| No-flash initial state | Seed stored choice via `addInitScript` before `goto`; assert attribute already correct on first paint |
| Head script is synchronous | Assert `applyTheme` script in `<head>` (in `admin_hooks.js`) is present and NOT `async`/`defer` |
| Do NOT assert computed colors | At most one `toHaveCSS` smoke to prove tokens wire through — no color-matching assertions |

### Return-Context Continuity (FLOW-01)

| Behavior | Assertion Method |
|----------|-----------------|
| URL-encoded scope restored | `?q=` / `order_by` query params present on return to list |
| Breadcrumb back-to-filtered-list | Breadcrumb link reconstructs the filtered list URL |
| Scope ribbon persistent | `sg-scope-ribbon` text unchanged across navigation |
| Impersonation banner persistent | Banner present across the full investigator journey |
| Filter + pagination restored as coherent set | All three (filter, pagination, scroll position) restored together — never partially |
