<objective>
Unify test/example/ on Sigra's canonical `user_sessions` session store (B6, D-06), and mirror the change into `priv/templates/sigra.install/*` so fresh installs land with the same behavior (D-07). Drop the phx.gen.auth `user_tokens` `context: "session"` rows entirely.

Purpose: Currently `ExampleWeb.UserAuth.log_in_user` writes to `user_tokens` (legacy phx.gen.auth store) via `Example.Accounts.generate_user_session_token`, but `Example.Accounts.list_sessions` queries `user_sessions` (Sigra's store) via `Sigra.Auth.list_sessions`. Result: the sessions page is permanently empty regardless of how many times the user logs in. The installer templates have the same split. This plan picks Sigra's store as the single source of truth and deletes the other path.
Output: Login writes to `user_sessions`; sessions page shows current session; installer templates mirror the fix; ConnTest locks the behavior.
</objective>

**Target (AFTER) — delegates to Sigra canonical store:**
```elixir
def generate_user_session_token(%User{} = user, opts \\ []) do
  metadata = %{
    type: :standard,
    ip: Keyword.get(opts, :ip),
    user_agent: Keyword.get(opts, :user_agent)
  }

  case Sigra.Auth.create_session(sigra_config(), user, metadata, []) do
    {:ok, session} -> session.token  # raw plaintext token for cookie
    {:error, reason} -> raise "Sigra.Auth.create_session failed: #{inspect(reason)}"
  end
end

def get_user_by_session_token(raw_token) when is_binary(raw_token) do
  hashed = Sigra.Token.hash_token(raw_token)
  config = sigra_config()
  session_config = config.session
  store = Keyword.fetch!(session_config, :store)
  opts = [repo: config.repo, session_schema: Keyword.fetch!(session_config, :session_schema)]

  case store.fetch(hashed, opts) do
    {:ok, session} -> Repo.get(User, session.user_id)
    {:error, :not_found} -> nil
  end
end

def get_user_by_session_token(_), do: nil

def delete_user_session_token(raw_token) when is_binary(raw_token) do
  hashed = Sigra.Token.hash_token(raw_token)
  Sigra.Auth.delete_session(sigra_config(), hashed, [])
  :ok
end

def delete_user_session_token(_), do: :ok
```
