# Phase 10.1.1 Plan 04: B9 Plain-Controller Login Page Summary

One-liner: Replaced `ExampleWeb.LoginLive` with `SessionController.new/2 + ExampleWeb.SessionHTML` so the login page is a dead render and the browser issues a real HTTP POST (fixes UAT B9 form-submit swallowing).

## What Shipped

1. **New `ExampleWeb.SessionHTML` module** with a `new/1` HEEx function
   rendering the magic-link form and the password form as plain `<form
   action="/users/log_in" method="post">` elements. No `phx-*`
   attributes (no LiveView process on the page → `<.form>` renders
   dead). Two form IDs: `magic_link_form` and `login_form`.

2. **`SessionController.new/2` updated** to assign BOTH `form` and
   `magic_link_form`, repopulating `email` from the flash so
   failed-login retries keep the field filled in.

3. **Router restructured:**
   - `get "/log_in", SessionController, :new` lives in the unauth scope
     OUTSIDE `live_session :redirect_if_user_is_authenticated`.
   - `live "/log_in", LoginLive` removed.
   - `get "/log-in/:token", SessionController, :magic_link` → underscore
     (`/log_in/:token`) — D-02 hyphen drift fix at the call site.

4. **`ExampleWeb.LoginLive` deleted.** No remaining references in
   `test/example/` (verified via grep).

5. **Installer template sync (D-07):**
   - `priv/templates/sigra.install/login_html.ex` — now uses
     `@magic_link_form` for the magic-link form and `@form` for the
     password form (was reusing `@form` for both). Module docstring
     updated to reflect the "always controller-mode login" decision.
   - `priv/templates/sigra.install/session_controller.ex` — `new/2`
     assigns both forms; `url_fun` hyphen fixed.
   - `priv/templates/sigra.install/login_live.ex` — DELETED. The
     installer no longer emits a LoginLive; `login_html.ex` is rendered
     in both `--live` and `--no-live` modes.

6. **`lib/mix/tasks/sigra.install.ex` updated:**
   - `ui_files` branch always includes the `login_html.ex → session_html.ex`
     file map entry in both `--live` and `--no-live` mode; `login_live.ex`
     entry removed.
   - Router injection: `live "/log_in", LoginLive` removed from the
     `--live` branch. `get "/log_in", SessionController, :new` is now
     emitted into the unauth scope unconditionally, alongside the
     existing `post "/log_in"` route. Magic-link token route underscore-
     corrected.
   - `rg "login_live" lib/mix/tasks/sigra.install.ex` → zero matches.
