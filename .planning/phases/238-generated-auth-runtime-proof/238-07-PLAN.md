## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| mounted LiveView → reset transaction | A user resolved at mount must not remain authorized after the signed reset credential expires or is consumed before submit. |
| raw browser email → normalized account/token/delivery | One untrusted address representation must resolve the same account for issuance and outbound delivery without creating an unusable credential. |
| browser logout action → persisted server session | A redirect or public login render cannot substitute for proof that the authenticated session token was revoked. |
| GitHub workflow metadata → evidence receipt | Remote success must belong to the exact correction commit and direct generated-host job, with earlier evidence retained rather than rewritten away. |
