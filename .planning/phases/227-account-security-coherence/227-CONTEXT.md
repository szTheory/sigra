# Phase 227 Context

Account-security screens must make current state, consequences, reversibility, and recovery posture legible under stress. MFA enrollment, backup codes, passkeys, sessions, and destructive actions reuse the Phase 224 vocabulary and keep security operations explicit.

The surface must remain usable in Light/Dark/System, keyboard-only navigation, reduced motion, forced colors, 320px reflow, 200% text, and long localized content. Clipboard enhancements never replace selectable recovery text.
