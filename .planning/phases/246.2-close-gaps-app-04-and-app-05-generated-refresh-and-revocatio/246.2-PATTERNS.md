## Shared Patterns

### Public credential boundary

**Sources:** `router_injection.ex:1-10,23-27`; `app_login_controller.ex:53-62`  
**Apply to:** refresh route and controller action.

- `[:api, :app_login_public]`, never browser/Sudo/`FetchAppSession`.
- Exact accepted key set and binary input check.
- Delegate to `Auth.AppSessions.refresh/1`; no controller token lifecycle code.
- Return only success credentials; map all lifecycle failures to one bounded unauthenticated response.

### Browser-owned mutation boundary

**Sources:** `lib/sigra/install/features/core.ex:764-770`; `api_token_controller.ex:70-85`  
**Apply to:** one-family and all-family revocation routes/actions.

- `[:browser, :require_authenticated, :require_sudo]` is mandatory and retains CSRF protection.
- Derive `owner = conn.assigns.current_scope.user` exclusively.
- Family ID is a selector only; never accept a user/owner parameter.

### Generated-host evidence

**Sources:** `generated-app-login-runtime-proof.sh:64-81,277-311,377-394,643-674`; `phase_246_generated_app_login_runtime_test.exs:9-42,73-92,586-621`  
**Apply to:** all new APP-04/APP-05 proof cases.

- Use real generated routes plus PostgreSQL, bounded readiness probes, deterministic database checks, and protected-route follow-up requests.
- Keep retained diagnostics outcome-classified and credential-free.
- Publish a receipt only after all flags pass, with exact current-HEAD source hashes.
