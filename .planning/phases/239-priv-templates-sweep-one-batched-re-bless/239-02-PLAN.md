## SAFETY RULESET (CRITICAL — do not bypass)

Format copied from `scripts/ci/admin-autofix-loop.sh:6-17`. These bind every task in this plan.

1. **Every edit names an explicit path** (D-23). Use per-file `Edit` operations. No
   `grep -rl … | xargs sed -i`. No `find . -name '*.ex' -exec sed`. No repo-wide `sed`. A repo-wide
   rewrite reaches 122 bookkeeping tokens in `.github/` and 45 indented `name:` lines; renaming a
   required status context hangs every PR forever with no error message anywhere.
2. **This commit's diff is entirely under `priv/templates/`.** Asserted mechanically in Task 3.
3. **Treat comment BLOCKS, not lines, as the edit unit.** `organizations/organizations.ex:59-60`
   wraps a single `.planning/` URL across two physical lines; a per-line strip leaves an orphan.
4. **Never touch markup or attributes inside a `~H` sigil** — only whole `<%%… %>` / `<%%= … %>`
   comment lines, or the text inside them. Removing `<%%` while leaving `%>` breaks compilation.
5. **The five D-03 exclusions stay.** They are not bookkeeping.
6. **A zero-match grep must be a measurement, not a fatal status.** Every `<automated>` check in
   this plan runs under `set -eo pipefail`, where a command substitution whose pipeline *starts* with
   a grep that finds nothing aborts the whole script — on the **success** path. Verified:
   `bash -c 'set -eo pipefail; n=$(printf "" | grep -E zzz | wc -l); echo reached'` prints nothing
   and exits 1. This plan's headline assertion is "the union grep returns zero", so it is exactly
   the shape that breaks. The house form is a brace group with `|| true` **inside** the substitution:
   `n=$( { grep -nE "$U" $(git ls-files priv/templates) || true; } | wc -l | tr -d " ")`. Keep that
   form if you touch any check here, and never add a bare `grep | wc -l` substitution.
7. **`priv/templates/` is absent from `.formatter.exs` inputs** (`:3-13` lists `{config,lib}/**`,
   `test/{sigra,support,mix}/**`, and `test/example/{lib,config,test,priv}/**`). Templates contain
   `<%= @module %>` interpolations that are not valid Elixir, so `mix format --check-formatted`
   does **not** police this commit. Do not run `mix format` over `priv/templates/`.

Safe: deleting the **entire** `<%%= # … %>` line, or rewriting the text inside while leaving
`<%%`/`<%%=` and `%>` intact. Unsafe: deleting the opener and leaving a stray `%>`; changing `<%%=`
to `<%%` or back (that changes the emitted tag in the generated file); touching any `:if={…}`
attribute or markup line.

**Assumption A1, carried forward explicitly and not eliminated:** `<% # … %>` and `<%= # … %>`
inside a `~H` sigil are compile-time comments that emit no markup, so deleting them cannot change
rendered HTML. This is reasoned from EEx/HEEx semantics plus the golden-tree evidence that the
rendered form is itself a comment — it is *not* proven by a render diff. Mitigation: the compile
gates catch syntax breakage, and the golden byte-diff in plan 239-04 catches any rendered change
reaching a generated file. **Treat any non-comment line in the re-bless diff for these 7 files as
the stop-the-line event D-12 anticipated.**
