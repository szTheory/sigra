   been caught in this phase. Every counting command in this plan must:

     `ugrep` wrapper that can silently return zero;
   - iterate file lists as **`git ls-files -z … | xargs -0 …`** — this shell does **not** word-split
     an unquoted `$(git ls-files …)` expansion, so the whole list arrives as one argument and every
     count comes back `0` (plan 239-11 hit this for real);

     and emitted zero records;

     zero-match grep aborts the shell and yields a confident false negative.
