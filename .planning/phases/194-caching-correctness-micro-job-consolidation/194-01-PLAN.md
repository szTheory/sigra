<objective>
Make GitHub Actions caching correct and observable (CACHE-01): bind every
deps+`_build` cache key to the resolved toolchain identity (OS + OTP + Elixir +
MIX_ENV + lockfile + a manual `-v1` buster) so a stale `_build` can never be
reused across an incompatible OTP/Elixir/MIX_ENV combo, surface cache hit-rate in
the CI step summary, and document the bust handle.

Purpose: Eliminate the stale-artifact correctness risk in the cache layer and
give maintainers a visible, documented bust mechanism — the foundation Phase 195
partition shards will cache against safely.

Output: An edited `.github/workflows/ci.yml` (11 precision-keyed cache blocks,
all with `id:`, cache-hit summary lines on the critical lanes) and a new
MAINTAINING.md cache-key/how-to-bust subsection.
</objective>
