<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub REST -> local collector | External run, ruleset, job and check-run JSON is untrusted data. |
| Source bundle -> offline replay | Retained bytes can be altered independently of their original API response. |

## STRIDE Threat Register (ASVS 5.0 Level 1; block high)

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-252-01 | Spoofing | Required check mapping | high | mitigate | Bind check and producer job by repository, run, attempt, SHA and IDs; reject name-only matches. |
| T-252-02 | Tampering | Source bundle | high | mitigate | Hash every retained response and verify before replay; a local hash is integrity evidence, not producer authority. |
| T-252-03 | Information Disclosure | API request ledger | medium | mitigate | Record endpoint identity without token, bearer header or signed download URL. |
| T-252-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package installs are planned; if an executor adds one, require the package-legitimacy audit and blocking human gate first. |
</threat_model>
