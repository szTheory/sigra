<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser JSON/CSRF → replay controller | All fields are untrusted identifiers/actions; only cookie current Scope owns the request. |
| Current Scope/partition → product authorization | Both must be re-evaluated at replay time; cached lease is not authority. |
| Concurrent requests → unique receipt/action | Exactly one transaction may create/apply a terminal outcome. |
| Stored receipt → public response | Response must be stable/idempotent and redact internal ownership/authorization data. |
