<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Manifest metadata → fetched bytes | Network/static bytes are untrusted until exact length and digest match. |
| Consumed response → Cache Storage | The consumed response cannot be reused; only a fresh response from verified bytes is written. |
| Cache Storage → IndexedDB marker | Cache success must precede marker creation; orphan bytes do not imply readiness. |
| Test control → production worker | Injected failure is bounded to a non-secret next-write control and cannot expose stored content or authority. |

## STRIDE Threat Register — ASVS Level 1

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-247-06 | Tampering | Media fetch/verification | high | mitigate | Full-buffer exact length and SHA-256 checks reject short and same-size altered responses before any write. |
| T-247-07 | Tampering / Repudiation | Cache/marker promotion | high | mitigate | Await Cache.put, write marker last, remove marker on all failures, and directly assert storage state. |
| T-247-08 | Information Disclosure | Worker failure protocol | medium | mitigate | Permit only bounded failure enums and counters; exclude bytes, digest, partition, credential, and mutation identity. |
| T-247-09 | Denial of Service | Cache rejection/quota | medium | mitigate | Fail to an actionable retry state and prove the portable injected failure path independently of experimental quota behavior. |
| T-247-SC | Tampering | Package installs | low | accept | No dependency is added. |
</threat_model>
