<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| HttpOnly browser session → Phoenix current Scope | Only server code receives authentication authority; page/worker/bootstrap never receive credentials. |
| Host manifest/media → browser verifier | Untrusted response bytes must match trusted length and digest before cache/marker promotion. |
| Cache Storage ↔ IndexedDB | No cross-store transaction exists, so availability requires marker-last plus both records at read time. |
| Root worker navigation fallback → authenticated `/app/lesson` | The `/app/`-scoped worker may return only the static credential-free shell offline; it never caches or substitutes an authenticated HTML response as authority. |
| Offline shell → partitioned local stores | Static shell begins with generic copy and may paint learner data only after the current activation pointer, lease, markers, and cached responses all match. |
| Partitioned browser state → replay endpoint | Cached lease/partition identify local state only; server current Scope and authorization decide replay. |
| Concurrent replay requests → PostgreSQL | Unique terminal identity and transaction prevent duplicate action application. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-247-01 | Information Disclosure / Elevation of Privilege | Bootstrap, JS, worker, storage, hooks | high | mitigate | Current-Scope cookie authentication stays server-only; schemas/messages expose bounded lesson/state fields and tests scan storage/protocols for credential-bearing keys. |
| T-247-02 | Tampering | Manifest/media promotion | high | mitigate | Compare exact byte count and SHA-256 over the complete buffer, await fresh-response cache writes, write marker last, and require marker plus cache response. |

| T-247-SC | Tampering | Package installs | low | accept | No package is added; Phoenix/Ecto, browser APIs, and pinned Playwright remain unchanged. |
