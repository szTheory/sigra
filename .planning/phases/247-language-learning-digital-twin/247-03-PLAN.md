<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| Runtime time/config → lease validity | Precision and invalid TTL values must not extend a lease accidentally. |
| Client partition → trusted current user | Partition is untrusted correlation input and cannot select owner/authentication. |
| Prior account state → replacement render | Logout/switch/expiry must clear visible and activatable prior data before new bootstrap. |
