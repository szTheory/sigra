## Trust Boundaries

| Boundary | Description |
|---|---|
| Current bootstrap → IndexedDB readers/writers | Every operation must carry the current partition and valid lease. |
| Logout/account switch → prior in-memory/DOM/storage state | Prior learner content must become unreachable before new account presentation. |
| `/app/` worker fallback → invalidated activation pointer | Offline navigation always returns a generic credential-free shell; local lesson data remains dark unless the complete current activation gate succeeds. |
| Offline form → outbox | Only validated bounded action data is stored; no authentication authority enters storage. |
| Theme/responsive CSS → accessible status/actions | Visual states cannot hide meaning or controls across themes/viewports. |
