<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| app credential → library | Raw opaque values are untrusted secrets and may only be hashed before lookup. |
| library → host schema | Sigra controls invariants while the adopter supplies Ecto modules. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-245-01 | Information Disclosure | `AppSession.issue/4` | high | mitigate | Assert raw credentials are absent from rows, audit metadata, logs, and exception inspection. |
| T-245-02 | Spoofing | `AppSession.authenticate/2` | high | mitigate | Bind digest lookup to `:access` and require active token plus active, unexpired family. |
| T-245-03 | Tampering | app-session config | medium | mitigate | Validate both schema modules and strict TTL ordering before persistence. |
| T-245-SC | Tampering | package installs | low | accept | No package-manager install occurs in this phase. |
</threat_model>
