<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| security event → credential families | A password reset or global sign-out must invalidate every applicable app credential. |
| transaction failure → caller | Partial success must never be reported as a completed security event. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-245-20 | Elevation of Privilege | password reset | critical | mitigate | Append app revoke to the existing reset Multi and prove fault rollback. |
| T-245-21 | Elevation of Privilege | sign-out-all | high | mitigate | Require durable app revoke before returning and deny every app credential on next use. |
| T-245-22 | Tampering | cross-user fanout | high | mitigate | Bind all updates to the target user and assert adjacent user rows remain active. |
| T-245-23 | Repudiation | security-event audit | medium | mitigate | Preserve the existing audit transaction/order and exclude app secrets from metadata. |
</threat_model>
