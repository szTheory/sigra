## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| IdP callback payload -> reconciliation service | Untrusted provider claims cross into library-owned account resolution. |
| reconciliation service -> database | Race-sensitive identity and membership writes must remain DB-enforced. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-124-01 | E | `Sigra.OAuth.EnterpriseReconciliation` | mitigate | Prevent email-collision account takeover by honoring D-02/D-03: require verified email, exact normalized single-user match, and reject conflicting identity or duplicate local matches with typed refusals. |
| T-124-02 | T | `Sigra.OAuth.EnterpriseReconciliation` membership branch | mitigate | Reuse `Sigra.Organizations.add_member_multi/5`, exact invite matching, and DB unique constraints so enterprise login cannot bypass organization invariants or stamp membership into the wrong org. |
| T-124-03 | D | identity and membership inserts | mitigate | Use `Ecto.Multi` plus constraint-aware recovery so concurrent callbacks cannot create duplicate identity or membership rows. |
| T-124-04 | R | refusal outcome mapping | mitigate | Return explicit refusal atoms and cover them in root tests so unsafe branches are auditable and distinguishable in later callback/session handling. |
</threat_model>
