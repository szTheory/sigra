<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated schemas -> `Sigra.DataExport.export_auth_data/3` | Host-generated Ecto records can include token hashes, encrypted tokens, TOTP secrets, passkey material, and backup-code hashes. |
| optional schema opts -> export payload | Missing schemas must be represented honestly so operators know which Sigra-owned sections are absent. |
| lifecycle fields -> account export section | Stored `deleted_at` and `scheduled_deletion_at` must be interpreted with the same lifecycle semantics used by account deletion. |
| user-scoped export -> organization/host domain boundary | Per-user export must not overclaim enterprise connection, SCIM, BI, legal certification, hosted-control-plane, or host-domain data coverage. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-127-05 | Information Disclosure | `fetch_user_records/4`, `fetch_audit_records/3`, backup-code summary | mitigate | Covers secret disclosure through raw auth structs: use per-section allowlists and Ecto `select: map(record, ^fields)`; never include `:hashed_token`, `:encrypted_access_token`, `:encrypted_refresh_token`, `:encrypted_secret`, `:credential_id`, `:public_key`, or `:hashed_code`. |
| T-127-06 | Repudiation | `omissions/1` | mitigate | Covers misleading partial exports/omission gaps: return structured omission maps for all optional schema options so partial exports cannot be mistaken for complete exports. |
| T-127-07 | Repudiation | `lifecycle_status/1` | mitigate | Covers lifecycle misrepresentation: call `Sigra.Account.Deletion.status/1` and serialize only `:scheduled`, `:deleted`, and `:not_scheduled` states. |
| T-127-08 | Repudiation | `enterprise` section and account export boundary | mitigate | Covers host-domain overclaim: keep enterprise connections as `[]`, `exported: false`, and reason `"Enterprise connections are organization-scoped and are not included in the user export contract."`; do not add host-owned data sections. |
| T-127-09 | Denial of Service | optional schema querying | accept | Phase 127 keeps existing bounded per-section queries by user id; broader pagination/streaming is outside EXP-01/EXP-02 and not required for ASVS L1 in this local export contract. |
</threat_model>
