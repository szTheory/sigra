Add **`test "audit_jwt_refresh_reuse writes api.jwt_refresh_reuse with failure outcome and metadata"`**: call **`APIToken.audit_jwt_refresh_reuse(cfg, user_id)`**, assert **one** row with **`action = 'api.jwt_refresh_reuse'`**, **`outcome = 'failure'`** (or column-appropriate), **`metadata->>'reason' = 'refresh_token_reuse_detected'`**.

Add **`test "audit_jwt_refresh is silent when audit_schema absent"`**: build **`cfg_no_audit = Sigra.Config.new!(...)`** matching **`sigra_config/1`** but **`audit: []`** (no **`audit_schema`**), call **`audit_jwt_refresh`**, assert **`count_where(..., \"action = 'api.jwt_refresh'\") == 0`**.        - In a **`try`/`after`**, **`ALTER TABLE audit_events ADD CONSTRAINT api_jwt_refresh_audit_guard CHECK (action <> 'api.jwt_refresh')`**.
       - **`ref = :telemetry.attach({__MODULE__, :jwt_refresh_guard}, [:sigra, :audit, :log_safe_error], &VerifyFailureTelemetryHandler.handle_event/4, self())`** (or a **new** handler module if reuse is confusing — either is fine).
       - **`assert :ok = APIToken.audit_jwt_refresh(cfg, user_id)`**.
       - **`assert_receive {:verify_failure_telemetry, [:sigra, :audit, :log_safe_error], %{count: 1}, %{action: \"api.jwt_refresh\", reason: :constraint_violation}}`** (adjust tuple tag if handler module differs).
       - **`assert count_where(repo, \"audit_events\", \"action = 'api.jwt_refresh'\") == 0`**.
       - **`after`**: detach telemetry; **`ALTER TABLE ... DROP CONSTRAINT api_jwt_refresh_audit_guard`**.

    5. Add **`test "audit_jwt_refresh_reuse fault injection emits log_safe_error and leaves no row"`** with constraint name **`api_jwt_refresh_reuse_audit_guard`** checking **`action <> 'api.jwt_refresh_reuse'`**, telemetry attach tuple **`{__MODULE__, :jwt_reuse_guard}`**, and **`assert_receive`** metadata **`action: \"api.jwt_refresh_reuse\"`**, **`reason: :constraint_violation`**.

    6. Keep **`async: false`**; reuse **`VerifyFailureTelemetryHandler`** only if message shape matches; otherwise add a second handler module mirroring it.

    7. Add a **small private helper** (e.g. **`with_audit_check_constraint(repo, constraint_name, check_sql, fun)`**) only if it materially reduces duplication for the two fault tests; otherwise inline **`try`/`after`** per existing file style.
