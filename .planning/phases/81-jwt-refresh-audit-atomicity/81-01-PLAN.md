  <action>
    1. Add a **private** function **`commit_api_token_jwt_audit(config, action, opts)`** where **`action`** is the string **`"api.jwt_refresh"`** or **`"api.jwt_refresh_reuse"`**, and **`opts`** is a **Keyword** that already includes **`api_token_audit_opts(config)`** merges, **scope-derived org/effective/actor** (via **`api_token_scope_fields/1`** on **`Sigra.Scope.from_config(config, %{id: user_id})`** — build scope in the **public** wrappers and pass **fully merged** opts into the commit helper), **`actor_id`**, **`target_id`**, **`metadata`**, and optionally **`outcome: "failure"`** for reuse.

    2. Inside **`commit_api_token_jwt_audit/3`**, mirror **`commit_api_token_verify_failure_audit/2`** structure:
       - If **`Keyword.get(opts, :audit_schema)`** is **`nil`**, return **`:ok`** without running a transaction.
       - Else build **`multi = Multi.new() |> Audit.log_multi_safe(action, opts)`** where **`opts`** already contains **`:audit_multi_step`** set by callers to **`:audit_api_token_jwt_refresh`** or **`:audit_api_token_jwt_refresh_reuse`** (atoms must match **`emit_telemetry_from_changes`** second argument list).
       - **`try do case config.repo.transaction(multi) do`** — **`{:ok, changes}`** → **`Audit.emit_telemetry_from_changes(changes, [opts[:audit_multi_step]])`** (pass the **atom** used as **`:audit_multi_step`**).
       - **`{:error, failed_step, %Ecto.Changeset{} = cs, _}`** when **`failed_step == opts[:audit_multi_step]`** → call a **new private** **`jwt_audit_emit_invalid_changeset(action, cs)`** that executes **`[:sigra, :audit, :log_safe_error]`** with **`%{count: 1}`** and metadata **`%{action: action, reason: :invalid_changeset, error_fields: ...}`** using the **same `error_fields` extraction pattern** as **`verify_failure_audit_emit_invalid_changeset/1`** (copy the **`Enum.map(cs.errors, ...)`** logic; do **not** hardcode verify-failure action string).
       - Unexpected **`{:error, failed, reason, _}`** → **`raise`** with a message prefix **`unexpected Ecto.Multi failure from Sigra.APIToken jwt audit:`** and **`inspect`** fragments.
       - **`rescue e`** → if **`verify_failure_audit_rescue?(e)`**, **`:telemetry.execute([:sigra, :audit, :log_safe_error], %{count: 1}, %{action: action, reason: :constraint_violation})`**; else **`reraise`**.

    3. Replace **`audit_jwt_refresh/2`** body with: build **`user_id`**, **`scope = Sigra.Scope.from_config(config, %{id: user_id})`**, **`merged = Keyword.merge(api_token_scope_fields(scope), api_token_audit_opts(config) ++ [actor_id: user_id, target_id: user_id, metadata: %{}, audit_multi_step: :audit_api_token_jwt_refresh])`**, then **`commit_api_token_jwt_audit(config, "api.jwt_refresh", merged)`**.

    4. Replace **`audit_jwt_refresh_reuse/2`** body with the same pattern using **`outcome: "failure"`**, **`metadata: %{reason: "refresh_token_reuse_detected"}`**, **`audit_multi_step: :audit_api_token_jwt_refresh_reuse`**, and **`commit_api_token_jwt_audit(config, "api.jwt_refresh_reuse", merged)`**.

    5. Update **`@doc`** on **both** public functions to state explicitly that **`:ok` does not guarantee** the audit row was persisted; operators should monitor **`[:sigra, :audit, :log_safe_error]`** (same honesty pattern as **`log_safe`**-based integrations).

    6. Update the **module `@moduledoc`** bullet that describes JWT / audit if it still claims **`log_safe`** for JWT refresh — change to **`Repo.transaction/1` + `Multi` + `log_multi_safe`** when **`:audit_schema`** is configured.
  </action>
