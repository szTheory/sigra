<objective>
Widen the axe accessibility tag set in both Playwright test helpers from WCAG 2.0 A/AA to the
full WCAG 2.1/2.2 AA surface, making "full-surface axe is clean" literally defensible against
the modern legal floor (EN 301 549, GOV.UK/DWP gate).

Purpose: GATE-02 requires "full-surface axe is clean." The current two-tag set ['wcag2a','wcag2aa']
covers WCAG 2.0 only. Widening to ['wcag2a','wcag2aa','wcag21a','wcag21aa','wcag22aa'] adds exactly
5 rules at zero new infra (axe-core 4.11.3 already supports all of them), per D-07. Any new violations
found are real bugs to fix in this phase; intentionally dense admin controls may suppress target-size
only per D-08, with a documented comment. The best-practice tag is NOT included (D-09).

Output: Both spec files updated with the wider tag array. If target-size fires, it is suppressed
inline with .disableRules(['target-size']) and a contract-citing comment.
</objective>
