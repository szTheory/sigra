# Phase 156 — UI Design Contract

> Visual and interaction contract for Phase 156: adopt shared components on baselined screens.
> Generated by gsd-ui-researcher. Verified by gsd-ui-checker.
>
> **Context:** This phase is a migration + seam-reconciliation pass — not a redesign. The
> `sg-*` token layer is mature and locked. No new tokens, CSS classes, or motion primitives
> are introduced. All design decisions below describe what the codebase already enforces and
> what the 6 coherence requirements (COHR-01..06) require as migration targets.

## Spacing Scale

The `sg-*` token layer uses a 4px base grid. All spacing values below map directly to
existing `--sg-space-*` custom properties. No exceptions introduced by this phase.

| Token | CSS Variable | Value | Usage |
|-------|-------------|-------|-------|
| xs | `--sg-space-1` | 4px (0.25rem) | Icon gaps, arrow-glyph gaps |
| sm | `--sg-space-2` | 8px (0.5rem) | Chip internal padding, tight clusters |
| md | `--sg-space-3` | 12px (0.75rem) | Default list gaps, `sg-list`/`sg-kv` gaps |
| base | `--sg-space-4` | 16px (1rem) | Card and notice internal padding, `sg-list-row` padding |
| lg | `--sg-space-5` | 20px (1.25rem) | — |
| xl | `--sg-space-6` | 24px (1.5rem) | Section-level gaps, `sg-empty-state` padding |
| 2xl | `--sg-space-8` | 32px (2rem) | Stack rhythm (`sg-stack--6` uses `--sg-space-6`) |

**Stack rhythm (page layout):** `sg-stack sg-stack--6` (24px gap between major page sections).
**Card rhythm:** `sg-stack sg-stack--3` (12px gap inside `sg-card` sections).
**Cluster rhythm:** `sg-cluster sg-cluster--between` (space-between alignment) for the
`page_back` + `scope_ribbon` header pair on detail screens.

Exceptions: none introduced by Phase 156. The `scope_ribbon` span carries zero additional
spacing; it inherits cluster gap from its `sg-cluster--between` container.

## Typography

All type values are tokens from the existing `--sg-text-*` / `--sg-weight-*` / `--sg-leading-*`
system. Sizes below are the resolved computed values (not raw em values).

| Role | CSS Token | Resolved Size | Weight Token | Resolved Weight | Line Height |
|------|-----------|--------------|--------------|-----------------|-------------|
| Body / UI text | `--sg-text-sm` | 14px (0.875rem) | `--sg-weight-regular` (450) | 450 | `--sg-leading-normal` (1.5) |
| Label / meta | `--sg-text-2xs` | 11px (0.6875rem) | `--sg-weight-bold` (800) | 800 | `--sg-leading-normal` (1.5) |
| Section heading | `--sg-text-md` | 18px (1.125rem) | `--sg-weight-bold` (800) | 800 | `--sg-leading-snug` (1.3) |
| Page title | `--sg-text-2xl` | clamp(1.6rem, 2.3vw, 2.4rem) | `--sg-weight-bold` (800) | 800 | `--sg-leading-tight` (1.1) |

**Phase-relevant type usages:**

- `scope_ribbon` output: `sg-muted sg-text-sm` — 14px, weight 450, color `--sg-color-muted`
  (`#686868` light / `#bdb5aa` dark). This span is decorative; no heading semantics.
- `notice` body: `sg-text-sm` inside `<p>` — 14px, weight 450, `1.5` line-height.
- `empty_state` title: `sg-empty-state__title` — inherits body size, weight `--sg-weight-semibold` (700).
- `empty_state` body: `sg-muted sg-text-sm` — 14px muted.
- `page_back` button: `sg-btn sg-btn--ghost sg-btn--sm` — 14px, weight 600 (semibold).
- `page_kicker`: `sg-page-kicker` — 14px, weight 700, uppercase, tracked wide.
- Mobile `sg-page-title` override at breakpoint: `1.5rem` (see `app.css:1454`).

| Accent (10%) — brand | `--sg-color-brand` `#c2410c` | (same) | Primary CTA buttons (`sg-btn--primary`) only |

|------|--------------------|---------------------|-------------------|--------------------|
| `ok` | mix(`--sg-color-ok-soft` 62%, panel) | `--sg-color-ok` `#176b43` | rgba(`--sg-color-ok-soft`, 0.16) | `#5dd1a0` |
| `warn` | mix(`--sg-color-warn-soft` 62%, panel) | `--sg-color-warn` `#a15c00` | rgba(`--sg-color-warn-soft`, 0.16) | `#f5c451` |

**Accent reserved for:**
- `sg-btn--primary` buttons (primary CTAs only — no other elements)
- `sg-brand-*` decorative elements in the topbar shell

**Accent NOT used for:** scope ribbon text, notice borders, empty states, page back buttons,
filter chips, scope pills (those use the muted/ink neutral scale).

**Notice tone merge (D-08 — CSS-only task):**
The duplicate tone rules between `.sg-list-row[data-tone="X"]` and `.sg-notice[data-tone="X"]`
at `app.css:945-993` are merged to a shared selector block:
```css
.sg-list-row[data-tone="ok"], .sg-notice[data-tone="ok"] { … }
```
The merged result stays inside `@layer sg-components`. No new class is introduced.
`.sg-list-row` without `data-tone` is preserved as a non-alert layout primitive.

## Component Interaction Contracts

### scope_ribbon (COHR-04)

**On list screens** (`UsersIndexLive`, `AuditIndexLive`): the scope prose is removed from the
`sg-page-copy` subtitle and replaced with `<.scope_ribbon copy={scope_copy(@admin_scope)} />`
as a discrete element. Placement: immediately after the `<header class="sg-page-header">` block
(not nested inside it). No `sg-cluster--between` wrapper on list screens (no `page_back` sibling).

**On detail/leaf screens** (`UserShowLive`): scope_ribbon stays in its existing
`sg-cluster sg-cluster--between` pair alongside `<.page_back>`. No change to positioning.

**Scope copy strings (default — kept byte-faithful per CONTEXT.md discretion):**
- `UsersIndexLive` global: `"Global user operations"` (existing `scope_copy/1`)
- `UsersIndexLive` org-scoped: `"{org.name} users"` (existing)
- `AuditIndexLive` global: `"Global audit explorer"` (existing)
- `AuditIndexLive` org-scoped: `"{org.name} audit"` (existing)
- `UserShowLive`: existing `scope_copy/1` strings unchanged

**Interaction:** Decorative — no ARIA role, no hover state, no focus state. Read inline by
screen readers as plain text.

### notice (COHR-05)

Call-site migration: replace `<div class="sg-list-row" data-tone={tone}>` alert rows with
`<.notice tone={tone}>` at:
- `user_show_live.ex:131` — identity card summary alert
- `organization_live.ex:71` — scoped-attention card alert (pixel-neutral, no baseline)

**Tone as atom:** The `notice/1` component attr is `tone: :atom` (`:ok`, `:warn`, `:risk`,
`:info`, `nil`). Call sites pass atom literals (e.g. `tone={:warn}`), not strings. The
component converts to string via `data-tone={@tone}` which Phoenix renders as the atom's
string form. Verify existing call-site `elem(summary_alert(@detail), 0)` returns an atom
before locking goldens (carried from 155-specifics).

**No live-region role** is applied by default. The `data-tone` attribute drives visual
treatment via CSS only. `role="alert"` is opt-in per `:rest` for post-load dynamic notices.

### page_back (COHR-03)

`UserShowLive` already uses an inline back-link. Phase 156 replaces it with `<.page_back>`:
```heex
<.page_back label="Back to users" return_to={@return_to} />
```
The component emits `<a class="sg-btn sg-btn--ghost sg-btn--sm" href={@return_to}><span aria-hidden="true">&larr;</span> Back to users</a>`.

`page_back` is leaf-only. List screens (`UsersIndexLive`, `AuditIndexLive`) have no `page_back`.

### empty_state (COHR-06)

Replace any remaining inline `sg-empty-state` blocks with `<.empty_state>`. The component
emits `<div class="sg-empty-state sg-stack sg-stack--3">` with title `<p>` and optional
muted body `<p>`. Static — no animation, no hover state.

### COHR-02 — UserShowLive header archetype change

The boxed `<section class="sg-card sg-stack sg-stack--3">` identity header at
`user_show_live.ex:97` is converted to the open `sg-page-header` archetype:

```html
<header class="sg-page-header">
  <p class="sg-page-kicker">Identity &amp; Status</p>
  <h1 class="sg-page-title">{display_name}</h1>
  <span class="sg-muted sg-text-sm">{email}</span>
  <code class="sg-code">{id}</code>
  …
</header>
```

The `<dl class="sg-summary-facts">` and `<.notice>` (formerly `sg-list-row` alert) remain
inside the header section but are no longer wrapped in a card surface. This is the intended
visual delta — deliberate re-record on the `user-detail` Playwright slug.

## Accessibility Contract

Requirements locked by axe WCAG A/AA gate (chromium + mobile + dark).

| Component | ARIA requirement |
|-----------|-----------------|
| `scope_ribbon` | No ARIA role. Decorative span — screen reader reads inline text. |
| `notice` (load-present) | No live-region role. Tone conveyed visually + textually. |
| `page_back` | Native `<a>` semantics. Arrow glyph `aria-hidden="true"`. Label is descriptive text. |
| `empty_state` | No ARIA. `<p class="sg-empty-state__title">` provides semantic heading. |
| `applied_chip` remove link | `aria-label={"Remove filter " <> chip.label}`. `&times;` is `aria-hidden="true"`. |
| `sg-page-header` (COHR-02 result) | Open `<header>` with `<h1>` — native landmark semantics. |
