<objective>
Make six local-only stashes durable on `origin`, retire five stale worktree admin records, and only
then empty the local stash list — with the drop gated behind an explicit decision checkpoint.

Purpose: REPO-03. Stashes are ordinary commit objects that exist nowhere but this machine. Once the
local list is emptied they are reachable only through the reflog, and this milestone forbids the
garbage-collection commands that would otherwise finish them off. The whole value of this plan is
the ORDER: preserve, prove preserved, then drop.

Output: a committed snapshot of all twelve SHAs, six archive refs on `origin`, one worktree entry,
and an empty stash list.
</objective>

<planner_decisions_closed_here>
**The archive ref namespace is a free choice, and it is fixed here as `refs/stash-archive/<date>/stash-N`.**
No existing convention was found on `origin` — the only safety-ish refs there today are three
ordinary branches. Fixing the namespace in the plan rather than leaving it to execution is what
makes the `git ls-remote` count assertion writable in advance.

**Two safety refs named by the roadmap's later branch-prune phase are NOT on `origin` today.** That
is recorded as a note for Phase 245 and is explicitly out of scope here — this plan creates only
the six stash archive refs.

**Resolvability is asserted twice, and the second time is what counts.** Checking `git cat-file -e`
before the drop proves only that a local object exists. The assertion that matters runs AFTER the
stash list is emptied.
</planner_decisions_closed_here>

(2) PRUNE WORKTREES with `git worktree prune`. Do NOT remove any directory beforehand. All five
stale entries point under the system temp directory and some of those directories may already be
gone — that is precisely why pruning first is prescribed: it retires git's own admin records
cleanly, whereas removing the directory first can leave a locked or half-removed record. If any
entry survives the prune, report it rather than forcing it; do not use `--force` without recording
why. Pruning a worktree does not delete any commit — the three detached entries carrying commits
keep their objects.

`origin` under the archive namespace fixed in this plan
(`refs/stash-archive/<today's date>/stash-<index>`). Push all six. If the remote rejects the custom
namespace, fall back to a branch namespace under `archive/` and record the fallback in the snapshot
file — but do not silently change namespace, because the verification counts refs by that prefix.

Then confirm the push landed by querying the remote, not by trusting the push output. Six refs must
be visible. Include a positive control in the same evidence — a remote query that returns a known
non-empty result — so the count is not a claim about a query that never ran.

Do NOT drop or clear any stash in this task. Do NOT delete any branch. Do NOT run any
garbage-collection, reflog-expiry or prune-now command.
