<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| rendered DOM/copy -> LLM prompt | Untrusted rendered content is fed to the judge; the model may be prompt-injected to fabricate an anchor |
| LLM output -> committed verdicts cache | Model output must be validated + anchor-checked before it is persisted |
| operator env -> SDK client | `ANTHROPIC_API_KEY` enters the SDK; must never be persisted or logged |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-217-05-INJECT | Tampering | prompt-injection via rendered DOM fabricating an anchor | high | mitigate | Every proposed anchor is pre-validated against the real DOM (cheerio `$()`, never eval/shell) BEFORE hashing; a hallucinated/injected anchor is dropped, not voted on; judge output is advisory only |
| T-217-05-KEY | Information Disclosure | API key leakage into a committed ledger/report/log | high | mitigate | Key env-only per D-03; verdicts store only a `prompt_sha`, never the prompt or key; call-counter test + a grep in the verify confirm no key is written |
| T-217-05-EOP | Elevation of Privilege | panel findings inflating open_findings | high | mitigate | Panel findings written ONLY to the parallel panel-findings.json; judge never writes findings.json or open_findings; verdicts-lint rejects any open_findings field |
| T-217-05-400 | Denial of Service | unsupported sampling params 400 the model | medium | mitigate | No temperature/top_p/top_k/prefill/fixed-thinking-budget per the verified claude-api contract; diversity is free across k=3 independent requests |
</threat_model>
