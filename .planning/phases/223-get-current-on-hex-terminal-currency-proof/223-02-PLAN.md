<objective>
PUB-05: Prove a clean adopter resolution against the real, post-retire Hex
registry (D-04). Stand up a throwaway scratch mix project declaring
`{:sigra, "~> 1.0"}`, run a **raw, unfiltered** `mix deps.get`, and assert
`mix.lock` locks `:sigra` at exactly `1.3.0` — not the stray `1.20.0`, not the
stale `1.1.0`. This reflects what a real adopter's build would resolve today.

Runs strictly AFTER the retire (depends_on 223-01): before the retire, this proof
would (correctly) lock `1.20.0` and fail.

Purpose: Demonstrate real adopter behavior, unfiltered — the authoritative signal,
not a preview (216 SC-5 / D-13 overclaim guard).
Output: A scratch project locking `1.3.0` + 223-02-SUMMARY.md with verbatim
evidence, feeding the PROOF-01 bundle in 223-03.

## Prohibition (D-05) — read before implementing
Do NOT drive this proof through `scripts/ci/lib/resolve-sigra-source.sh` (or set
`SIGRA_UPGRADE_SMOKE_EXCLUDE_VERSIONS`). That resolver hardcodes
`exclude="${SIGRA_UPGRADE_SMOKE_EXCLUDE_VERSIONS:-1.20.0}"` at line 44 —
artificially dropping the stray before selection. Using it would claim adopter
resolution is clean while a genuine `mix deps.get` might still lock `1.20.0`. The
proof MUST be a plain `mix deps.get` with no exclusion env and no resolver helper.
