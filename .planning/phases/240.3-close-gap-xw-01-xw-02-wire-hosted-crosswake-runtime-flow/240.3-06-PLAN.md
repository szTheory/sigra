## Trust Boundaries

| Boundary | Description |
|---|---|
| query-bearing callback -> redirect response | Untrusted correlation input is processed into a fixed allow or recovery redirect. |
| callback response -> next same-origin document request | Browser referrer behavior can otherwise copy the full callback URL into downstream request metadata. |
