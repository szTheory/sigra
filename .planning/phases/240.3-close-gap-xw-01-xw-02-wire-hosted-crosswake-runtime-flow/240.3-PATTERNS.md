### `test/example/lib/example_web/controllers/crosswake_controller.ex` (controller, request-response)

**Analog:** `test/example/lib/example_web/controllers/enterprise_sso_controller.ex`

**Start/return orchestration and explicit response mapping** (lines 26-52, 55-115):

```elixir
def create(conn, %{"org" => org_slug} = params) do
  with {:ok, routing} <- Organizations.get_routable_enterprise_connection(org_slug),
       {:ok, authorize_url, session_params} <- oauth_module().authorize_url(...) do

    |> put_session(@enterprise_session_key, session_params)

def callback(conn, %{"org" => org_slug} = params) do
```

Use this thin `with`/`case` controller shape, but do **not** store the continuation in the Plug session or accept an external URL. Return claims first, passes untrusted params only as `evaluate_return/5` evidence, and maps result to either a fixed local `303` or the two generic recovery flashes. The `303` pattern is:

```elixir

|> put_status(:see_other)
|> redirect(to: fixed_safe_path)
```

## Shared Patterns

### Fresh session authority and evidence-only returns

**Source:** `test/example/lib/example/accounts/crosswake_session_adapter.ex` lines 48-60, 89-105, 139-151.

```elixir
with {user, session} <- Accounts.get_user_and_session_by_token(raw_token),
     :ok <- validate_current_session(session, as_of),
     current_binding <- binding(user, session),
     :ok <- match_binding(expected_binding, current_binding),
     {:ok, lane} <- new_lane(current_binding, session, as_of),
     {:ok, context} <- Contracts.new_auth_context(%{session_authority_lane: lane}),
     evaluator_result <- evaluator(opts).(route, context, expected_session_version: current_binding.session_version) do
  format_evaluator_result(evaluator_result, current_binding)
else
  nil -> deny(:session_unavailable)
  {:error, :binding_mismatch} -> deny(:binding_mismatch)
end
```

Persist the departure binding and pass callback parameters only to `evaluate_return/5`; never recompute a return-time expected binding or let callback data select host authority/navigation.

### Browser route and session boundary

**Sources:** `test/example/lib/example_web/router.ex` lines 7-15, 52-56; `test/example/test/support/conn_case_helpers.ex` lines 49-56.

Reuse the browser pipeline for session fetch/CSRF/current scope. Scope start behind authentication; scope return under browser only. Request tests must use a real Plug session seeded with the normal `:user_token` key.

### Generic recovery and safe navigation

**Source:** `test/example/lib/example_web/controllers/enterprise_sso_controller.ex` lines 75-113.

Clear any host-only transaction state as appropriate, use a generic flash, and redirect to a fixed local route. Crosswake success specifically uses `put_status(:see_other)` before local `redirect/2`; no raw input may survive into the final URL/DOM.

### Deterministic proof and redaction

**Sources:** `test/example/priv/playwright/playwright.config.ts` lines 58-64; `scripts/ci/hosted-session-interop-proof.sh` lines 18-23, 95-108.

Use fixed test clocks, real Ecto rows, a single serial no-retry browser journey, bounded shell commands, and receipt-last creation. Redaction assertions are a functional requirement, not documentation-only proof.
