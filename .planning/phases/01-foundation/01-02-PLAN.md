## Threat Model

| Threat | Mitigation | Verification |
|--------|------------|--------------|
| Sensitive data in telemetry metadata | Whitelist-only metadata policy: user_id (not email), boolean outcome, operation context. Never raw params or user structs. | Grep telemetry.ex for email, password, token, secret — must not appear in metadata maps |
| Session fixation via cookie reuse | FetchSession plug assigns current_scope from token lookup, does not trust cookie value directly | Plug reads token, dispatches to SessionStore.fetch, does not deserialize cookie payload |

| Bearer token exposure in logs | FetchBearer extracts token from header but never logs it; only passes to verify | Grep fetch_bearer.ex for Logger — must not log the token value |
| Sudo mode bypass | RequireSudo checks authenticated_at timestamp against configurable window | Test: stale sudo window -> conn halted with :stale_sudo error type |
</threat_model>

    **lib/sigra/plug/error_handler.ex (per D-30):**
    ```elixir
    defmodule Sigra.Plug.ErrorHandler do
      @moduledoc """
      Behaviour for handling authentication errors in the HTTP pipeline.

      ## Error Types

        * `:unauthenticated` - No authenticated user found
        * `:stale_sudo` - Sudo window has expired, re-authentication required
        * `:rate_limited` - Request rate limit exceeded

      ## Example

          defmodule MyAppWeb.AuthErrorHandler do
            @behaviour Sigra.Plug.ErrorHandler

            @impl true
            def auth_error(conn, :unauthenticated, _opts) do
              conn
              |> Phoenix.Controller.put_flash(:error, "You must log in to access this page.")
              |> Phoenix.Controller.redirect(to: "/login")
            end
          end
      """

      @type error_type :: :unauthenticated | :stale_sudo | :rate_limited
      @callback auth_error(Plug.Conn.t(), error_type(), keyword()) :: Plug.Conn.t()
    end
    ```

    **lib/sigra/plug/fetch_session.ex (per D-28):**
    - `@behaviour Plug`
    - `@moduledoc` — Fetches the current user from session token and assigns `current_scope`
    - `init(opts)` — validates required `:session_store` option (defaults to `Sigra.SessionStores.Ecto`), `:scope_module` option. Returns opts.
    - `call(conn, opts)` — Reads session token from `get_session(conn, :user_token)`. If present, calls `session_store.fetch(token, opts)`. On `{:ok, user}`, assigns `current_scope` via scope_module. On error or nil token, assigns `current_scope: nil`.
    - This is a STUB in Phase 1 — the actual SessionStore.Ecto implementation comes in Phase 4. The plug structure and contract is established now.
    - `@doc since: "0.1.0"` on public functions

    **lib/sigra/plug/fetch_bearer.ex (per D-28, D-31):**
    - `@behaviour Plug`
    - `init(opts)` — accepts `:token_verifier` option (module with `verify/2`)
    - `call(conn, opts)` — Reads `Authorization` header via `Plug.Conn.get_req_header(conn, "authorization")`. Parses `"Bearer " <> token`. If found, calls `token_verifier.verify(token, opts)`. Assigns `current_scope` on success. Assigns nil on missing/invalid.
    - NEVER logs the raw token value.
    - `@doc since: "0.1.0"`

    **lib/sigra/plug/require_authenticated.ex (per D-28):**
    - `@behaviour Plug`
    - `init(opts)` — requires `:error_handler` option (module implementing `Sigra.Plug.ErrorHandler`)
    - `call(conn, opts)` — Checks `conn.assigns[:current_scope]`. If nil, calls `error_handler.auth_error(conn, :unauthenticated, opts)` then `Plug.Conn.halt(conn)`. If present, returns conn unchanged.

    **lib/sigra/plug/require_sudo.ex (per D-28):**
    - `@behaviour Plug`
    - `init(opts)` — accepts `:error_handler` and `:sudo_window` (default: `5 * 60` = 300 seconds)
    - `call(conn, opts)` — Checks `conn.assigns[:current_scope]` exists. Then checks `conn.assigns[:authenticated_at]` timestamp. If `DateTime.diff(DateTime.utc_now(), authenticated_at) > sudo_window`, calls `error_handler.auth_error(conn, :stale_sudo, opts)` and halts. Otherwise passes through.
