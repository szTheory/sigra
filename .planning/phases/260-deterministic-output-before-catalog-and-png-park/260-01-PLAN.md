<objective>
Author the park PR (BGEN-06, ADR 005 decision 7, owner decision #7) as its own small branch cut from `origin/main`, in a separate git worktree, so Phase 260 and Phase 261 visual changes can later merge without the ubuntu-native PNG compares reddening the required `Example Playwright smoke (full lifecycle)` check.

Mechanism (planning decision OQ3, Option A with default-on compare): the PNG comparison is skipped through an explicit env switch `SIGRA_PNG_COMPARE_SKIP` set to `1` only on the three PR/push shard steps. Unset means compare-on, so both recapture jobs, `scripts/ci/run-playwright-drift.sh`, `scripts/ci/snapshot-recapture-gate.sh`, the cross-lane compare step and `playwright-github-pages.yml` keep comparing with no edit. Axe and behavior specs stay on the PR path (ADR 005 decision 7), which Option B (whole-lane demotion) would have removed.

Recorded departure (RESEARCH Open Question 4, now RESOLVED there): the research recommendation was to also add the flag to `playwright-github-pages.yml`. This plan declines it on purpose: with default-on compare an unset switch compares, so that workflow keeps comparing with no edit, it is not a required context and not part of `ci-gate`, and leaving it untouched keeps the park PR a `ci.yml`-only change (process budget). The cost, a red non-required Pages run after Phase 261 until recaptured, is documented in MAINTAINING.md (Task 2).

Purpose: remove the CI-gate deadlock before any visual byte changes (milestone gate "CI-gate deadlock avoidance").
Output: a local branch plus worktree holding the park change, ready for plan 04 (verify, owner-approved push and merge).
</objective>
