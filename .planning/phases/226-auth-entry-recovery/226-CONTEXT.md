# Phase 226 Context

Generated auth is a neutral host-owned starting point. Its markup should describe intent through `sigra-auth-*`, not bind adopters to DaisyUI/Tailwind, the mature admin `sg-*` system, or the Tasklane demo `vt-*` system.

Entry and recovery flows use one configured primary action, progressive disclosure for alternatives, native forms, user-language errors, and stable autofill/paste semantics. The compatibility selectors remain scoped for existing generated apps but are not used by the modernized templates.
