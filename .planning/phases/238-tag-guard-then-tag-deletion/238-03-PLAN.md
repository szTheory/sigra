|----------|-------------|
| GitHub Settings UI → the live ruleset | Anyone with admin access can delete or weaken the guard with no diff and no review |
| committed snapshot → CI assertion | The snapshot is the reference value; if it drifts from the live object silently, the guard protects nothing |
| pull_request lane → external network | The guard must not cross this boundary; the observer lane may |
