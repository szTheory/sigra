<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| login-page form input -> template controller redirect | Generic discovery must not leak whether arbitrary domains belong to inactive or duplicate enterprise setups. |
| scoped route params -> template enterprise controller | The template controller must load org-owned connection truth from Sigra, not trust raw slug params alone. |
| template callback branches -> rendered retry UI | Error handling must preserve enterprise mode and explicit org truth without silently switching auth modes. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-123-06 | I | template login discovery form | mitigate | Use generic bounded failure copy on the generic surface and only reveal org name after Sigra has resolved explicit org context per D-11/D-12. |
| T-123-07 | T | `EnterpriseSSOController` authorize path | mitigate | Route every enterprise authorize through the canonical `/organizations/:org/sso` controller and library lookup; never start OIDC from the generic discovery POST per D-01/D-02. |
| T-123-08 | E | org-scoped entry route | mitigate | Reuse existing org-scoped route posture and fetch the persisted org-owned connection rather than accepting arbitrary connection ids. |
| T-123-09 | R | generated-host callback UX | mitigate | Keep bounded failure reasons explicit in controller branches and enterprise retry UI; do not redirect to default password login on enterprise-specific failures per D-08/D-09. |
</threat_model>
