<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generic discovery input -> enterprise routing decision | Untrusted email input must never produce heuristic or multi-match org routing. |
| org/connection resolution -> OAuth redirect state | Organization truth must survive the browser redirect without trusting plain params or transient assigns. |
| OAuth callback params -> first session row | Callback-time org drift or disabled connections must be rejected before session and audit truth are written. |
| library session metadata -> auth selector | Enterprise callback must not lose the initiating org because the generic active-org selector overwrote it. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-123-01 | S | `Sigra.EnterpriseRouting.discover_connection/2` | mitigate | Allow auto-route only for one exact normalized domain mapped to one `:active` connection with a verified unique ownership signal per D-04/D-05. |
| T-123-02 | T | `Sigra.OAuth.authorize_url/3` enterprise context | mitigate | Put `{organization_id, connection_id, routing_source}` inside signed state and returned session params; reject callbacks when either copy is missing or mismatched per D-06. |
| T-123-03 | E | `Sigra.OAuth.Callback` | mitigate | Re-fetch the persisted enterprise connection by bound ids and reject disabled or unavailable state before returning any session metadata. |
| T-123-04 | R | `Sigra.Auth.create_session/4` | mitigate | Treat explicit enterprise `active_organization_id` as authoritative and keep `session.create` audit emission after that org is resolved. |
| T-123-05 | I | discovery failure surface | mitigate | Return only bounded reasons (`no_org_match`, `multiple_org_matches`, `org_connection_unavailable`) in errors and audits; do not leak domain inventory or inactive-org details. |
</threat_model>
