## Spacing Scale

The admin design system uses a rem-based `--sg-space-*` token scale defined in `sigra_admin.css:~22–30`. The values do not precisely follow the 8-point scale; they use a 0.25rem step ladder (4px increments at 16px base font).

| Token | Value | Usage |
|-------|-------|-------|
| `--sg-space-1` | 4px (0.25rem) | Icon gaps, tight inline padding |
| `--sg-space-2` | 8px (0.5rem) | Compact element spacing, chip padding |
| `--sg-space-3` | 12px (0.75rem) | Small cluster gaps, field-help trigger padding |
| `--sg-space-4` | 16px (1rem) | Default element spacing, card padding |
| `--sg-space-5` | 20px (1.25rem) | Medium cluster gaps |
| `--sg-space-6` | 24px (1.5rem) | Section padding, panel rhythm |
| `--sg-space-7` | 28px (1.75rem) | (available, rarely used directly) |
| `--sg-space-8` | 32px (2rem) | Large section breaks |
| `--sg-space-10` | 40px (2.5rem) | Layout gaps |
| `--sg-space-12` | 48px (3rem) | Major section breaks |

Exceptions:
- `--sg-control-xs: 1.75rem` (28px), `--sg-control-sm: 2.25rem` (36px), `--sg-control-md: 2.75rem` (44px), `--sg-control-lg: 3rem` (48px) — named control-height tokens for buttons and inputs; do not use raw pixel values.
- `--sg-pill-h: 1.625rem` (26px) — pill height token.
- Target-size minimum for interactive admin controls: 24×24 CSS px (documented; dense admin UI precedent from Phase 206 D-08). `--sg-control-md` (44px) meets full WCAG 2.5.8 target for primary actions.

Source: `sigra_admin.css:22–30, 95–100` (pre-populated from codebase).

## Typography

The admin type scale uses `--sg-text-*` and `--sg-weight-*` tokens. Only the tokens relevant to the 5 Wave B components and the L0 token layer are surfaced here; the full token set lives in `admin-token-reference.md`.

| Role | Token / Size | Weight Token | Line Height |
|------|-------------|--------------|-------------|
| Body / base | `--sg-text-base` = 1rem (16px) | `--sg-weight-regular` = 450 | 1.5 |
| Small / muted text | `--sg-text-sm` = 0.875rem (14px) | `--sg-weight-regular` = 450 | 1.5 |
| Label / chip | `--sg-text-xs` = 0.75rem (12px) | `--sg-weight-semibold` = 700 | 1.2 |
| Heading / section | `--sg-text-md` = 1.125rem (18px) | `--sg-weight-semibold` = 700 | 1.2 |

Notes on Wave B component typography (pre-populated from design contract and codebase):

- **`empty_state`**: `sg-empty-state__title` uses base body; secondary muted copy uses `sg-muted sg-text-sm`. Static — no interactive states.
- **`page_back`**: `sg-btn--sm` uses `--sg-text-sm` at `--sg-weight-semibold` (inherits from `.sg-btn` typography contract). Arrow glyph is `aria-hidden`.
- **`scope_ribbon`**: `sg-muted sg-text-sm` — 14px at regular weight. Static.
- **`field_help` trigger**: inherits button typography from `.sg-field-help__trigger`; panel tooltip copy is `--sg-text-sm`.
- **`skeleton`**: no visible text — visual placeholder only.

Only 2 weights are used in Wave B component surfaces: `--sg-weight-regular` (450) and `--sg-weight-semibold` (700). Do not introduce `--sg-weight-medium` (600) or `--sg-weight-bold` (800) for these components.

Source: `sigra_admin.css:34–46`, `admin-design-contract.md:84–165` (pre-populated from codebase).

## Color

The admin color system uses `--sg-color-*` tokens with full light/dark/system support. All values are pre-defined; no raw hex or raw px values may appear outside `:root` `--sg-*` token declarations (COMP-03 requirement).

| Role | Light Token / Value | Dark Override | Usage |
|------|--------------------|--------------|----|
| Dominant (60%) — page canvas | `--sg-color-subtle` = `#f6f5f2` | `#171614` | Page background under all admin surfaces |
| Secondary (30%) — cards, panels | `--sg-color-panel` = `#ffffff` / `--sg-color-panel-alt` = `#fbfaf7` | `#1f1d1a` / `#25221e` | Card surfaces, admin shell panels, tooltip backgrounds |
| Accent (10%) — brand ember | `--sg-color-brand` = `#c2410c` | (unchanged in dark) | See accent reserved list below |
| Destructive | `--sg-color-risk` = `#b42318` | `#f8a39c` | Destructive action labels, risk-tone notices only |

**Accent reserved for** (explicit list — COMP-03 / admin-ui-principles):
- Primary action buttons (`.sg-btn--primary`)
- Focus indicators (`--sg-focus-ring` is `color-mix(brand 35%, transparent)`)
- Selected filter chip fills (`.sg-filter-chip[aria-pressed="true"]`)
- Ownership-boundary emphasis (scope indicators with brand tint)
- Admin topbar organization-scope accent border
- Ember rail accent mark in the Sigra logo lockup (`--sg-logo-rail-ember`)

Accent is **not** used for headings, every icon, or general-purpose decoration.

**Wave B component color contract:**
- `empty_state` dashed border: `--sg-color-line-strong` (not brand accent)
- `scope_ribbon` text: `--sg-color-muted` via `.sg-muted` class
- `field_help` trigger hover: `--sg-color-brand` text color; active: `scale(0.96)` press — no raw hex
- `skeleton` shimmer gradient: must use `--sg-color-panel-alt` and `--sg-color-line` (no raw hex)
- `page_back` hover/active: inherited from `.sg-btn--ghost` token-based transitions

**Token-layer conformance (COMP-03):**
- No raw hex outside `:root` `--sg-*` declarations — enforced by `scripts/ci/admin-css-conformance.sh` (built in Phase 206, extended this phase for raw-px)
- No raw px outside `:root` `--sg-*` declarations — new conformance extension (D-07)
- `admin-token-reference.md` documents all 96 `--sg-*` :root properties; a CI completeness guard (D-06) diffs `:root` LHS defs against documented backtick tokens

Source: `sigra_admin.css:58–90, 175–210` (pre-populated from codebase).

## Copywriting Contract

Phase 207 is an audit-and-gap-fix elevation pass on 5 existing components. It does not introduce new surfaces, new empty states, or new user-visible flows. All copywriting is pre-existing and governed by the design contract and admin-ui-principles. The table below documents the existing copy contracts that must be preserved (not changed) during this phase.

| Element | Component | Copy Contract |
|---------|-----------|---------------|
| Empty state heading | `empty_state` | Contextual — authored per call site; component accepts `<p class="sg-empty-state__title">` slot. Must be plain, short, sentence-case. Examples: "No users found", "No sessions", "No organizations". |
| Empty state body | `empty_state` | Optional — `<p class="sg-muted sg-text-sm">` below heading. Provides next step when filtering is in play (e.g. "Try clearing your filters"). Must not appear for genuinely empty sets without a recovery action. |
| Back navigation label | `page_back` | "Back to {context}" — descriptive, not just "Back". Examples: "Back to users", "Back to user". Do not use generic "Back". |
| Scope indicator | `scope_ribbon` | "Global scope" or "{Org name} scope" — rendered via `scope_copy/1` helper. Must match topbar `sg-scope-pill` semantics; never contradict the shell chrome scope indicator. |
| Field help trigger | `field_help` | `aria-label="Help: {field label}"` — matches the `for` label exactly. Panel tooltip copy: one plain-language sentence answering "what does this affect?". No links, buttons, or nested controls inside the tooltip. |
| Skeleton aria | `skeleton` | No visible copy — containing section carries `aria-busy="true"`. Replacement content announces itself when loaded. |
| Error state (general) | `notice` (not Wave B, but referenced) | Tone `risk`: problem description + what to do next. Example: "Email confirmation link has expired. Request a new confirmation email." |

**Destructive actions in this phase:** None. Phase 207 is CSS/token audit work with no user-facing destructive flows. The conformance guard scripts are developer tooling only.

**CI guard copy (developer-facing):**
- Token completeness guard failure: "admin-token-reference.md is missing {N} token(s): {list}. Run 'mix sigra.install' or update the doc to match sigra_admin.css :root." (exact wording at Claude's discretion during implementation)
- Raw-px/hex guard failure: "sigra_admin.css contains raw {hex|px} outside :root --sg-* declarations at line {N}: {value}. Use a --sg-* token instead." (exact wording at Claude's discretion)

Source: `admin-design-contract.md:84–165`, `admin-ui-principles.md` (pre-populated from codebase).

## Motion Contract

Phase 207 must verify (and fix if needed) that all 5 Wave B components comply with the following motion contract. This is the primary interaction-state contract for this phase.

| Component | Motion Allowed | prefers-reduced-motion |
|-----------|---------------|------------------------|
| `empty_state` | None — static display | N/A |
| `page_back` | Hover/active: `--sg-transition-tone` (color/bg/shadow at 140ms `--sg-ease`). Focus: `--sg-focus-ring` only, no transform. | Global block at `sigra_admin.css:~1467` strips transitions |
| `scope_ribbon` | None — static display | N/A |
| `field_help` | Trigger: `scale(0.96)` on active (`--sg-transition-press` at 120ms). Panel: `--sg-transition-tooltip` (opacity + transform at 180ms `--sg-ease-out`). No layout shift on panel toggle. | Global block strips transform/animation |
| `skeleton` | Shimmer: `translateX` `@keyframes` via `.sg-skeleton-shimmer` (~`sigra_admin.css:1419`). Composite-safe (GPU layer, transform-only). Infinite loop is intentional for loading feedback. | Global block: `animation-iteration-count: 1 !important` + `animation-duration: 0.01ms !important` — leaves a static block, no shimmer |

**Hard rules (from admin-ui-principles and 206 precedent):**
- No `transition: all` on any component — verified by `scripts/ci/admin-css-conformance.sh`
- No per-component `@media (prefers-reduced-motion)` blocks needed — rely on the existing global block at `sigra_admin.css:~1467`
- No animation on keyboard-frequent paths (filter chips, list navigation)
- Motion-only with pointer device for hover-triggered transforms: use `@media (hover: hover) and (pointer: fine)` guard where relevant

## Accessibility Contract

| Component | axe Gate | ARIA Contract | Target Size |
|-----------|---------|--------------|-------------|
| `empty_state` | 0 violations across chromium/mobile/dark | No additional ARIA; `<p class="sg-empty-state__title">` provides semantic context | N/A — not interactive |
| `page_back` | 0 violations across chromium/mobile/dark | Native `<a>` — inherits link semantics; `&larr;` is `aria-hidden="true"`; link text is descriptive (not just "Back") | `sg-btn--sm` height ≥ 28px CSS px; near-threshold documented per D-08 precedent |
| `scope_ribbon` | 0 violations across chromium/mobile/dark | Decorative scope copy — no additional ARIA; screen readers read `<span>` inline | N/A — not interactive |
| `field_help` | 0 violations across chromium/mobile/dark | Trigger: `type="button"`, `aria-label="Help: {label}"`, `aria-controls={id}`, `aria-expanded`; Panel: `role="tooltip"`, `hidden` until toggled; Escape closes and restores focus | `sg-field-help__trigger` ≥ 24×24 CSS px (near-threshold documented) |
| `skeleton` | 0 violations across chromium/mobile/dark | No ARIA on skeleton itself; containing section carries `aria-busy="true"` | N/A — not interactive |
