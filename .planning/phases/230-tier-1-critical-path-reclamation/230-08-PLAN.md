<objective>
Emit the honest-skip set as a durable artifact so Phase 231 does not inherit an undocumented baseline.

`ci-gate` counts `skipped` as a pass (`ci.yml:1502`). Every job-level and step-level condition this
phase adds enlarges the set of constructs that legitimately do not run on a pull request — and
GATE-03's whole job in Phase 231 is to distinguish "skipped because correctly gated for this event"
from "skipped because its gate rotted". That distinction is only auditable against an enumerated
list. Without one, Phase 231 has to reverse-engineer the intended set from the same YAML it is
supposed to be checking.

`MAINTAINING.md` already carries the pre-existing non-PR job list from Phase 196 plus an accepted-
residuals subsection in the same shape. This phase extends that list rather than starting a parallel
one. A phase SUMMARY is not acceptable: those archive at milestone close while GATE-03 and GATE-05
need this live.

Purpose: make every skip this phase introduces auditable by name.
Output: two new subsections in `MAINTAINING.md`'s CI cadence section.
</objective>
