<objective>
Split the design gallery spec so the ~84 per-board PNG assertions can be event-gated while the WCAG
accessibility signal stays on every PR — the coverage-neutral collapse the owner ratified in D-01.

The 28 board tests today each run an identical full-document axe scan (`admin-design.spec.ts:64-66`
calls `new AxeBuilder({ page })` with no `.include()`, and every board test reaches it in the same
page state). Those ~84 scans carry the rule coverage of one scan per project. Collapsing them to one
full-page scan per design project preserves every non-redundant axis — viewport and theme, the two
axes on which `color-contrast` and `target-size` genuinely differ — and lets the pixel half move off
the PR lane.

Purpose: make the PR/non-PR partition of this spec expressible and enforceable.
Output: a tagged spec whose test inventory is pinned by an ExUnit contract test.

Note per D-22: this phase is **not** a pure-YAML change set. FAST-02 requires editing a Playwright
spec file, so the phase manifest legitimately lists `test/example/priv/playwright/tests/admin-design.spec.ts`.
Revertibility survives — a tag-plus-grep split reverts by deleting the tag argument and the CLI flag.
