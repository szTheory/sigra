<objective>
Retire the D-13 stopgap pin (HARD-01, D-03/D-04). Replace the hand-maintained
`SIGRA_UPGRADE_SMOKE_START_VERSION: "1.3.0"` floor at ci.yml:643 with a durable, self-maintaining
exact-stray-exclusion inside the upgrade-smoke version resolver, so the resolver stops out-sorting the
real GA to the immutable stray Hex release `1.20.0`.

Per 222-RESEARCH.md Finding 1 (verified live this session): the stray `1.20.0` is NOT retired
(`retirement: None`; it is Hex's current `latest_stable_version`) and `mix hex.info sigra` renders NO
`(retired)` marker for any version. D-03's literally-named "drop `(retired)` rows" filter matches zero
rows and does not work. The verified fix is an exact fixed-string exclusion (`grep -vxF '1.20.0'`)
inserted between the series grep and `sort -V | tail -1`. This fully honors D-03's INTENT (durable, no
hand-maintained floor); only the mechanism name changes from retired-filter to stray-exclusion.

Purpose: make the PR-invisible upgrade-smoke gate un-rot-able at the resolver level and remove the pin,
which is itself a per-release silent-rot vector.
Output: a sourceable, offline-testable resolver lib; a stray-exclusion; the removed pin; an offline
resolver self-test; extended phase_147 structural coverage.
</objective>
