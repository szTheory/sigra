<objective>
Implement **D-45-02** hybrid OAuth: **T1** — compose **`Sigra.Audit.log_multi_safe/3`** (or **`__log_internal__/3`**) inside the same **`Ecto.Multi`** / **`repo.transaction`** as **`repo.insert` / `repo.update` / `repo.delete`** for **`Sigra.OAuth.Callback`** registration and **`Sigra.OAuth`** link/unlink. **T2** — keep **`log_safe`** for **`oauth.authorize`**, pre-persistence callback failures, and token-exchange failures without domain commits. Eliminate duplicate post-commit **`log_safe`** rows for paths now covered inside Multi (e.g. **`:registered`** success in **`handle_callback/4`**).
</objective>
