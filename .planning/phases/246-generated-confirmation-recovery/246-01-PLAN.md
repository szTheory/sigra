## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser GET/event -> generated LiveView | Link token and event payload are untrusted; current scope is server assigned. |
| LiveView -> Sigra.Auth -> Repo | Verified HMAC token selects account; transaction updates account and deletes credentials. |

## STRIDE Threat Register (ASVS L1; high blocks)

|-----------|----------|-----------|----------|-------------|-----------------|
| T-246-01 | Tampering | ConfirmationLive.handle_params | high | mitigate | D-01: GET stores display state only; fresh-host probe asserts confirmed_at remains nil until submit. |
| T-246-02 | Spoofing | ConfirmationLive.confirm_link | high | mitigate | D-02: HMAC token selects its owner, no login/session call, persisted owner and visitor session assertions. |
| T-246-03 | Denial of service | ConfirmationLive code/resend | medium | mitigate | D-03: nil scope branches to guidance without dereference or delivery attempt. |
| T-246-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new package-manager install task exists; use pinned, previously installed dependencies and existing CI setup. |
