## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| library → generated template | Library calls `apply(config.emails_module, :organization_invitation, [...])` — the generated template is the injection point for all user-controllable fields in rendered email HTML |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-17-10 | Injection (XSS into email HTML) | `organization_invitation_email.ex` HTML body | mitigate | Every user-controllable field interpolation MUST go through `html_escape/1` (or `Phoenix.HTML.html_escape/1`). Fields that MUST be escaped: `inviter.name`, `inviter.email`, `org.name`, `invitation.email`, `invitation.role`, `product_name`. The `accept_url` does NOT need escaping in the HTML body because it goes into a `href` attribute — but it MUST still be a library-generated, HMAC-signed value (responsibility of Plan 17-03), not attacker-controlled. Checker grep target: search for raw `#{...}` interpolation against user fields without `html_escape` wrap. |
| T-17-10 (phishing) | Spoofing (email provenance) | Subject line + body | mitigate | Subject MUST include BOTH inviter display name AND org name (phishing defense per D-12 + UI-SPEC). Body paragraph MUST name inviter, org, role, and product so invitee can verify provenance. Tests assert subject contains `org.name` literal. |
| T-17-02 (link integrity) | Tampering (accept URL) | `accept_url` parameter | accept (inherited from Plan 17-03) | The template trusts the caller's `accept_url`. Plan 17-03's `build_accept_url/2` is the source of truth — the URL contains a `Plug.Crypto.sign`'d envelope with email HMAC-bound (T-17-02 mitigation lives in Plan 17-02/03). The template just renders it. |
| T-17-10 (plaintext ignore copy) | Social engineering | "Safely ignore" fine print | mitigate | Fine print MUST include the phrase "if you weren't expecting this invitation, you can safely ignore this email" — legitimate invites NEVER demand urgent action. Locked copy per UI-SPEC. Tests assert the substring is present. |

</threat_model>

```elixir
defmodule <%= app_module %>Web.Emails.OrganizationInvitationEmail do
  @moduledoc """
  Phase 17 D-12 — generated invitation email.

  Mirrors the v1.0 `ApiTokenCreatedEmail` shape: host app owns this file,
  edits copy, inline CSS, subject line directly. The library owns *when*
  to send (dispatched from `Sigra.Organizations.Invitations.create/2`'s
  after-commit hook) and *what shape* the arguments are.

  ## Security notes

  - Every user-controllable field interpolation goes through `html_escape/1`.
  - Subject line includes both inviter name and org name (phishing defense).
  - Accept URL is HMAC-signed by the library (`Sigra.Token.generate_invite_envelope/2`);
    this template does not generate or validate it.
  - Fine print reassures invitee they can safely ignore unexpected invites.
  """

  import Swoosh.Email
  import <%= app_module %>Web.Gettext
  import Phoenix.HTML, only: [html_escape: 1, safe_to_string: 1]

  @font_family "-apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, sans-serif"

  @doc """
  Builds the organization-invitation email.

  ## Parameters

  - `invitation` — `%OrganizationInvitation{email, role, expires_at}`
  - `org` — `%Organization{name}`
  - `inviter` — `%User{email, name}` (name may be nil)
  - `accept_url` — HMAC-signed accept URL (library-generated, never raw token)
  """
  @spec organization_invitation_email(struct(), struct(), struct(), String.t()) ::
          Swoosh.Email.t()
  def organization_invitation_email(invitation, org, inviter, accept_url)
      when is_binary(accept_url) do
    inviter_display =
      case inviter do
        %{name: name} when is_binary(name) and name != "" -> name
        %{email: email} -> email
      end

    product_name = "<%= app_name %>"

    subject_line =
      dgettext("sigra", "%{inviter} invited you to join %{org}",
        inviter: inviter_display,
        org: org.name
      )

    html_content = build_html(invitation, org, inviter_display, accept_url, product_name)
    text_content = build_text(invitation, org, inviter_display, accept_url, product_name)

    base_email()
    |> to(invitation.email)
    |> subject(subject_line)
    |> html_body(wrap_html(html_content))
    |> text_body(text_content)
  end

  defp build_html(invitation, org, inviter_display, accept_url, product_name) do
    org_name = escape(org.name)
    inviter_escaped = escape(inviter_display)
    role_label = humanize_role(invitation.role)
    product_escaped = escape(product_name)
    expires_formatted =
      Calendar.strftime(invitation.expires_at, "%B %d, %Y at %I:%M %p UTC")
    expires_date =
      Calendar.strftime(invitation.expires_at, "%B %d, %Y")

    """
    <h1 style="margin: 0 0 16px 0; font-size: 24px; font-weight: 600; line-height: 1.2; color: #18181b; font-family: #{@font_family};">
      #{dgettext("sigra", "You're invited to join %{org}", org: org_name)}
    </h1>

    <p style="margin: 0 0 16px 0; font-size: 16px; line-height: 1.5; color: #3f3f46; font-family: #{@font_family};">
      #{dgettext("sigra", "%{inviter} invited you to join %{org} as %{role} on %{product}.",
          inviter: inviter_escaped, org: org_name, role: role_label, product: product_escaped)}
    </p>

    <div style="margin: 24px 0; padding: 16px; background-color: #f4f4f5; border-radius: 8px;">
      <p style="margin: 0 0 8px 0; font-size: 14px; color: #71717a; line-height: 1.5; font-family: #{@font_family};">
        <strong>#{dgettext("sigra", "Organization:")}</strong> #{org_name}
      </p>
      <p style="margin: 0 0 8px 0; font-size: 14px; color: #71717a; line-height: 1.5; font-family: #{@font_family};">
        <strong>#{dgettext("sigra", "Role:")}</strong> #{role_label}
      </p>
      <p style="margin: 0; font-size: 14px; color: #71717a; line-height: 1.5; font-family: #{@font_family};">
        <strong>#{dgettext("sigra", "Expires:")}</strong> #{expires_formatted}
      </p>
    </div>

    #{cta_button(dgettext("sigra", "Accept invitation"), accept_url)}

    <p style="margin: 24px 0 8px 0; font-size: 14px; color: #71717a; line-height: 1.5; font-family: #{@font_family};">
      #{dgettext("sigra", "Or copy and paste this link into your browser:")}
    </p>
    <p style="margin: 0 0 16px 0; font-size: 14px; color: #71717a; line-height: 1.5; font-family: #{@font_family}; word-break: break-all;">
      #{accept_url}
    </p>

    <p style="margin: 24px 0 0 0; font-size: 14px; color: #71717a; line-height: 1.5; font-family: #{@font_family};">
      #{dgettext("sigra", "If you weren't expecting this invitation, you can safely ignore this email. It will expire on %{date}.", date: expires_date)}
    </p>
    """
  end

  defp build_text(invitation, org, inviter_display, accept_url, product_name) do
    role_label = humanize_role(invitation.role)
    expires_formatted = Calendar.strftime(invitation.expires_at, "%B %d, %Y at %I:%M %p UTC")
    expires_date = Calendar.strftime(invitation.expires_at, "%B %d, %Y")

    """
    #{inviter_display} #{dgettext("sigra", "invited you to join")} #{org.name} #{dgettext("sigra", "as")} #{role_label} #{dgettext("sigra", "on")} #{product_name}.

    #{dgettext("sigra", "Organization:")} #{org.name}
    #{dgettext("sigra", "Role:")} #{role_label}
    #{dgettext("sigra", "Expires:")} #{expires_formatted}

    #{dgettext("sigra", "Accept the invitation:")}
    #{accept_url}

    #{dgettext("sigra", "If you weren't expecting this invitation, you can safely ignore this email.")}
    #{dgettext("sigra", "It will expire on")} #{expires_date}.
    """
  end

  defp escape(value) when is_binary(value) do
    value |> html_escape() |> safe_to_string()
  end

  defp humanize_role(role), do: role |> to_string() |> String.capitalize()

  # base_email/0, wrap_html/1, cta_button/2 are reused from the shared
  # helpers module — match whatever api_token_created_email.ex imports.
  # If those helpers live in the same file via `defp`, copy them here too.
end
```
