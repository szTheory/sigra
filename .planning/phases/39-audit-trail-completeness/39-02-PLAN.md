  <action>
    1. Add `alias Ecto.Multi` and `alias Sigra.Audit` at top of `api_token.ex` if not already present (keep alias style consistent with file).
    2. Replace the **`case config.repo.insert(changeset)`** success/failure structure in **`do_create/4`** with:
       - Build **`multi = Multi.new() |> Multi.insert(:api_token, changeset)`**.
       - Compute the same **`scope`** value currently passed to `Audit.log_safe("api.token_create", scope, ...)` (the `case config.scope_module` block stays **before** building multi).
       - Build **`audit_opts`** as **`Keyword.merge/2`** of **`api_token_audit_opts(config)`** and explicit keys matching today’s effective audit payload: **`actor_id: user.id`**, **`target_id: user.id`**, **`metadata: %{name: attrs.name, scopes: attrs.scopes}`**, plus **`organization_id`**, **`effective_user_id`**, **`actor_id`** as derived from **`scope`** the same way `Sigra.Audit.log_safe/3` would merge `scope_fields(scope)` with caller opts (read `lib/sigra/audit.ex` `scope_fields/1` **behavior** — duplicate the three ids + org into `audit_opts` explicitly because `scope_fields` is private).
       - Append audit: **`multi = Sigra.Audit.log_multi_safe(multi, "api.token_create", audit_opts)`** — note **`log_multi_safe`** skips audit append when **`audit_schema`** nil.
       - Run **`config.repo.transaction(multi)`** and map results:
         - **`{:ok, %{api_token: token_record} = changes}`** → call **`Sigra.Audit.emit_telemetry_from_changes(changes)`**, then **`{:ok, raw_key, token_record}`** (reuse existing **`raw_key`** / **`hashed_token`** locals **before** transaction).
         - **`{:error, :api_token, %Ecto.Changeset{} = cs, _}`** → **`{:error, cs}`**.
         - Other **`{:error, step, reason, _}`** → re-raise or normalize to **`{:error, changeset}`** only if such branch is reachable; prefer matching only `:api_token` insert failures for public contract.
    3. Remove the standalone **`Sigra.Audit.log_safe("api.token_create", ...)`** call from the old success branch — must not remain (grep gate below).
    4. If **`audit_schema`** is nil, transaction still runs **insert-only** multi (audit helper returns unchanged multi) — behavior must match prior "insert always attempted".
  </action>
