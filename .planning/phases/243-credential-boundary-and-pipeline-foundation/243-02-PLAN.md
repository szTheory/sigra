## ASVS posture

Level 1; blocking threshold high.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Authorization header → JWT verifier | Untrusted compact token reaches the explicitly selected JWT verifier. |
| App-session request → public foundation | Unimplemented credential input must not cross into authenticated state. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-243-05 | Spoofing | `FetchJWT.call/2` | high | mitigate | Invoke only `JWT.verify_access/2`, reload the user, and fail closed on every verifier/user failure. |
| T-243-06 | Information Disclosure | JWT fact projection | high | mitigate | Copy only enumerated verified fields into a fresh exact facts map; test raw/arbitrary claim absence. |
| T-243-07 | Elevation of Privilege | `FetchAppSession.call/2` | high | mitigate | Authenticate nothing until Phase 245; emit nil Scope and no private facts. |
| T-243-08 | Tampering | Credential selection | medium | mitigate | Separate public Plug modules; no token-shape classifier or cross-kind fallback. |
</threat_model>
