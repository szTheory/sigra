<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser to passkey options routes | Untrusted page input crosses into Phoenix controller JSON endpoints. |
| Served JS to LiveView hooks | Browser runtime receives LiveView events and starts WebAuthn ceremonies. |
| Browser to controller completion POST | Browser submits WebAuthn response JSON and CSRF token to session-mutating controller endpoints. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-21-12-01 | Tampering | `test/example/priv/static/assets/js/app.js` passkey options fetch | mitigate | Preserve CSRF header and POST-only options fetches copied from existing passkey helper. |
| T-21-12-02 | Elevation of Privilege | Passkey registration/delete completion | mitigate | Keep final enrollment and delete mutation in existing sudo/controller routes; JS must only initiate ceremonies and submit forms. |
| T-21-12-03 | Information Disclosure | Browser errors in login status | mitigate | Map browser errors to safe recovery buckets; do not render raw `AbortError`, `NotAllowedError`, stack traces, or exception messages. |
| T-21-12-04 | Denial of Service | Repeated browser ceremonies | accept | Existing server-side ceremony rate limiting and challenge TTL from Phase 20 are the authoritative controls. |
</threat_model>
