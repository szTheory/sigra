Create `lib/sigra/session_stores/ecto.ex` — `Sigra.SessionStores.Ecto` implementing all 7 SessionStore callbacks.

The Ecto store operates against the user's generated `UserSession` schema. It receives the schema module via opts (`:session_schema` key). Pattern:

```elixir
defmodule Sigra.SessionStores.Ecto do
  @behaviour Sigra.SessionStore

  @impl true
  def create(user_id, metadata, opts) do
    repo = Keyword.fetch!(opts, :repo)
    schema = Keyword.fetch!(opts, :session_schema)
    {raw_token, hashed_token} = Sigra.Token.generate_hashed_token()

    attrs = %{
      user_id: user_id,
      hashed_token: hashed_token,
      type: to_string(Map.get(metadata, :type, :standard)),
      ip: Map.get(metadata, :ip),
      user_agent: Map.get(metadata, :user_agent),
      geo_city: Map.get(metadata, :geo_city),
      geo_country_code: Map.get(metadata, :geo_country_code),
      last_active_at: DateTime.utc_now(),
      inserted_at: DateTime.utc_now()
    }

    case repo.insert(struct(schema, attrs)) do
      {:ok, record} ->
        session = to_session(record)
        {:ok, %{session | token: raw_token}}
      {:error, _} = error -> error
    end
  end
  # ... implement all 7 callbacks
end
```

Key implementation details:
- `fetch/2`: Query by hashed_token, convert to Session struct via `to_session/1`. Do NOT populate `:token` field (raw token is ephemeral).
- `delete/2`: Delete where hashed_token matches.
- `list_by_user/2`: Query all records for user_id, ordered by inserted_at desc, convert each to Session struct. Enrich each with `Sigra.UAParser.parse(record.user_agent)` into `:parsed_ua`.
- `delete_all_for_user/2`: Delete all where user_id matches. Accept optional `:except_token` in opts to exclude current session. Return `{count, nil}`.
- `update_activity/3`: Update last_active_at and optionally ip/user_agent where hashed_token matches.
- `update_sudo/3`: Update sudo_at where hashed_token matches.
- Private `to_session/1` converts Ecto record to `%Sigra.Session{}`.
