| Boundary | Description |
|---|---|
| Generated installer → host router | Generator text becomes executable host authentication configuration; omitted options can make every protected PAT route unavailable. |
| HTTP Authorization header → `FetchAPIToken` | Untrusted bearer transport crosses into credential verification and must not be confused with other credential kinds or browser state. |
| Verified PAT row → live host identity | Persisted credential ownership must be revalidated against the current user row before normal Scope construction. |
| Authentication facts → test probe response/diagnostics | Bounded facts may be observed for proof, but raw PAT material must remain secret. |
