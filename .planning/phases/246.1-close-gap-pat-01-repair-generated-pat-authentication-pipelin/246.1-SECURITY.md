# Phase 246.1 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Generated installer → host router | Generator text becomes executable host authentication configuration; omitted options can make every protected PAT route unavailable. | Host configuration function and Scope module references |
| HTTP Authorization header → `FetchAPIToken` | Untrusted bearer transport crosses into credential verification and must not be confused with other credential kinds or browser state. | Raw bearer credential (secret) |
| Verified PAT row → live host identity | Persisted credential ownership must be revalidated against the current user row before normal Scope construction. | Token owner ID, live user record, granted scopes |
| Authentication facts → test probe response/diagnostics | Bounded facts may be observed for proof, but raw PAT material must remain secret. | User ID and bounded credential metadata |
