## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| generated JS hook → browser WebAuthn API | Untrusted browser exceptions and aborts cross back into LiveView via hook events |
| installer → host app asset entrypoint | Generator mutations touch user-owned `assets/js/app.js` and must remain deterministic and reversible |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-20-09 | T | `inject_app_js_passkeys/2` | mitigate | Use marker-comment detection as the authoritative gate; only establish the marker block when the standard Phoenix placement shape is present, otherwise fall back to manual instructions |
| T-20-10 | D | generated passkey hooks | mitigate | Emit explicit aborted/error outcomes and abort in-flight ceremonies on `destroyed`/`disconnected` so LiveView reconnect churn does not strand browser operations |
| T-20-11 | I | custom asset fallback instructions | accept | Manual instructions expose import and hook-registration lines only; they do not leak secrets or private runtime values |
| T-20-12 | E | hook registration merge | mitigate | Merge into `...colocatedHooks` instead of replacing the hooks map, preventing accidental privilege loss in existing host hooks |
</threat_model>
