`sigra:passkeys:<registration|authentication>:user:<user_id>` with the validated
`passkeys[:ceremony_rate_limit]` values and the configured `Sigra.RateLimiter`.

| T-20-06 | T | `config.passkeys` tunables | mitigate | Validate enums and bounds in `Sigra.Config` plus `validate_runtime_passkeys!/1`; do not silently coerce bad values |
| T-20-07 | D | `Sigra.Passkeys.rate_limit_ceremony/3` | mitigate | Use a per-user key namespace with a default 5/min window to cap ceremony-initiation floods |
| T-20-08 | I | runtime config cache | accept | Cached config values are process-local operational data, not secrets; `secret_key_base` already exists elsewhere in `%Sigra.Config{}` |
