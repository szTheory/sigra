# Phase 142 — UI Design Contract

> Visual and interaction contract for Phase 142: Dev Credentials Page & App Framing.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn is React/Next.js; this is Phoenix/LiveView) |
| Preset | not applicable |
| Component library | daisyUI (Tailwind CSS plugin — already present in `ExampleWeb.CoreComponents`) |
| Icon library | Heroicons (already present via `<.icon name="hero-*">` in CoreComponents) |
| Font | System font stack (no custom font; Phoenix 1.8 default) |

**Note:** shadcn gate does not apply — the stack is Elixir/Phoenix LiveView + Tailwind CSS + daisyUI. The existing `core_components.ex` already uses daisyUI classes (`table-zebra`, `alert`, `badge`, `menu`, `navbar`, `btn`, `rounded-box`, `toast`, `base-100/200/300`, `base-content`). All new UI must use the same class vocabulary.

## Spacing Scale

Declared values (must be multiples of 4). Source: existing app layout patterns (`px-4 sm:px-6 lg:px-8`, `py-20`, `max-w-2xl`, `space-y-4` from `layouts.ex`).

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding |
| sm | 8px | Table cell padding, inline element spacing |
| md | 16px | Default element spacing, horizontal padding unit |
| lg | 24px | Section padding, card internal padding |
| xl | 32px | Layout gaps between sections |
| 2xl | 48px | Page top/bottom padding |
| 3xl | 64px | Not used in this phase |

Exceptions: none. The `<main>` layout wrapper uses `py-20` (80px) which is outside the 8-point scale — this is a pre-existing app constraint; the credentials page inherits it unchanged.

## Typography

Source: existing `core_components.ex` and `layouts.ex` patterns confirmed throughout the codebase.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (text-sm) | 400 (normal) | 1.5 |
| Label / Table header | 14px (text-sm) | 600 (semibold) | 1.5 |
| Section heading | 18px (text-lg) | 600 (semibold) | 1.75rem (leading-8, existing `<.header>` pattern) |
| Page title / app name | 14px (text-sm) | 600 (semibold) | 1.5 |

**Constraints:**
- The `<.header>` component (existing) renders `text-lg font-semibold leading-8` — reuse it for the credentials page section heading.
- The `<.table>` component (existing) renders `table table-zebra` — reuse it for the persona table.
- No new font sizes or weights are introduced in this phase.

## Color

Source: daisyUI semantic tokens already in use throughout `admin_shell.ex`, `core_components.ex`, `layouts.ex`. All values are daisyUI design tokens, not raw hex — they adapt to the active theme.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg-base-100` | Page background, table rows |
| Secondary (30%) | `bg-base-200` | Page header/nav bar, card backgrounds, sidebar, table header row |
| Accent (10%) | `text-primary` / `bg-primary` (Phoenix orange `#FD4F00`) | Dev-only warning badge on the page, "DEV ONLY" label |
| Destructive | `alert-error` / `text-error` | Not applicable in this phase — no destructive actions |

Accent reserved for: the "DEV ONLY" environment badge displayed prominently on the credentials page. No other elements in this phase use accent color.

**Dev-only visual signal:** The `/demo/credentials` page must carry a visible `badge badge-warning` (daisyUI yellow) bearing "DEV ONLY — not visible in production" so evaluators instantly understand the page's scope. This is a DEMO-01 contract requirement, not a style preference.

## Interaction Contract

This phase has no interactive form elements. It is a read-only reference page.

| Interaction | Behavior |
|-------------|----------|
| Navigate to `/demo/credentials` in dev | Renders credentials table; no authentication required |
| Navigate to `/demo/credentials` in test/prod | Route does not exist (compile-env gate); returns 404 |
| Page load with empty DB | Shows error state copy (above) — graceful fallback if seeds not run |
| Copy password from table | No JS copy-to-clipboard widget — plain selectable `<code>` text is sufficient for evaluator use |
